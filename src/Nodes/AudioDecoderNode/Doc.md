# Audio Decoder

## 1. 节点说明

播放媒体库中的单个音频文件，按声道分离输出 AudioData。波形显示与播放进度内嵌于节点界面；通道数随文件自动调整。

支持**节点间同步（SyncData 体系）**：既可作为**从机**被外部同步源（时间线、LTC Decoder、其他解码器）驱动播放/暂停/seek，也可作为**主机**发布自身播放头供下游节点跟随。

多曲目列表播放请用 **Audio List Decoder**；需要混音/路由时配合 Audio Matrix 使用。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 4 | 否 | 4 | 4 | —（不可新增） | 末端口为 SYNC（从机跟随源） |
| 输出 | 3 | 是 | 1 | 不限 | AudioData | 0/1 为 CH 声道口，**末端口（2）为 SYNC 同步发布**；声道数随媒体文件调整 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。

### 输入

| 端口 | 类型 | 必接 | 说明 |
|------|------|------|------|
| PLAY | VariableData | 否 | 播放/停止（布尔），写入 `playing` 属性；断开时：保持当前状态 |
| LOOP | VariableData | 否 | 是否循环（布尔），写入 `loop` 属性；断开时：保持当前值 |
| GAIN | VariableData | 否 | 音量（数值），写入 `volume` 属性；断开时：保持当前值 |
| SYNC | SyncData | 否 | **同步源绑定（从机）**：接入后由源的播放头驱动本节点播放/暂停/seek；断开恢复本地控制 |

### 输出

| 端口 | 类型 | 说明 |
|------|------|------|
| CH 0 / CH 1 … | AudioData | 各声道音频（共享时间戳环形缓冲），播放时连续输出；声道数随文件自动调整 |
| SYNC（末端口） | SyncData | **同步发布（主机）**：共享同步状态句柄，每 40ms 切片发布播放头锚点，供下游节点跟随 |

## 3. 界面与属性

界面控件显示在右侧属性面板：文件选择下拉框（媒体库列表）、播放/停止按钮、循环复选框、音量滑块、波形显示（含播放头，异步解码真实波形、缓存命中即时显示）。

| 属性 | 类型 | 默认值 | 取值范围 | 说明 |
|------|------|--------|----------|------|
| file | string | 空 | 媒体库相对路径 | 音频文件路径（存取均相对媒体库目录） |
| loop | bool | false | true/false | 循环播放 |
| volume | double | 1.0 | 0～1 | 音量 |
| playing | bool | false | true/false | 播放状态（可写=播放/停止） |
| progress | double | 0 | 只读 0～1 | 播放进度反馈（`/progress`） |

保存到工程：`values.filePath`（媒体库相对路径）、`values.isLoop`、`values.volume`、`values.play`（兼容旧字段 `autoPlay`），加载时恢复并按 `play` 自动起播。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`（{别名} 为节点别名，{节点ID} 为节点编号）

| 地址 | 类型 | 范围 | 说明 |
|------|------|------|------|
| /file | string | 媒体库相对路径 | 切换音频文件（自动重新初始化解码器） |
| /loop | bool | true/false | 循环开关 |
| /volume | float | 0～1 | 音量 |
| /play | bool | true/false | 播放/停止 |
| /stop | bool | true 时生效 | 停止播放（专用命令地址） |
| /progress | float | 只读 | 播放进度反馈 |

以上地址均通过 `registerExternalBinding` 注册（`/file`、`/volume`、`/loop`、`/play` 与内嵌控件双向绑定），并订阅全局事件总线 Command 事件。

## 5. 行为细节

- **状态与持久化**：文件路径（相对媒体库）、循环、音量、播放状态均保存到工程；重开工程后按 `play` 自动起播。
- **时序/性能**：波形峰值解码在后台线程异步执行（有缓存），期间先显示由时长生成的占位波形；解码期间切换文件不会写回旧结果（ABA 保护）。
- **错误行为**：文件为空或初始化失败时 `isReady = false`、波形显示"音频初始化失败"；输入端口数据断开（`nullptr`）时忽略，不影响当前播放状态。
- **路径**：保存/加载均把文件路径转换为媒体库相对路径，跨机器移动工程不受盘符影响。
- **SYNC 从机（跟随）**：In 3 接入 SyncData 后，解码循环每 40ms 将源期望位置与自身播放头比较——偏差在死区（默认 40ms，≤1 帧）内不动作；超限写入内部 seek 通道执行 `av_seek_frame` + 清空缓冲，并用首个数据包 pts 重锚定。源播放态变化联动本节点启停；源失联（500ms 无心跳）按定格处理。
- **SYNC 主机（发布）**：Out 末端口输出共享同步状态；每个音频切片发布一次位置 + 全局帧计数锚点，跟随端按全局时钟外推。
- **时间基准**：图内同步以 TimestampGenerator 全局帧计数为唯一时钟；SMPTE 时间码不进图内（LTC Decoder/Generator 负责边界转换）。

## 6. 使用说明与典型接法

1. 从媒体库选择音频文件并播放。
2. 将各 CH 接到矩阵、混音或 Audio Device Out。
3. 外部控制：`/file`、`/volume`、`/loop`、`/play`（`/stop` 触发停止）。
4. **多节点同步**：时间线/LTC Decoder 的 SYNC 输出接 In 3 即成为从机；本节点 Out SYNC 也可作为时钟源驱动其他节点。

## 7. 示例

Audio Decoder → Audio Matrix → Audio Device Out，多轨预览。

**时间线同步**：TimeLineNode Out(SYNC) → Audio Decoder In(SYNC)，时间线播放/暂停/seek 自动带动音频。
