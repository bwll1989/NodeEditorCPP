# ModBus Slave Coil

## 1. 节点说明

通用 **Modbus TCP 从机（Slave）—— 纯被控**：在本机监听 TCP 端口，**只响应主站**对线圈的读/写；本地面板与 OSC **不得改写**线圈表，避免反向拉动主站读到的状态。

| 通道 | 方向 | 说明 |
|------|------|------|
| Modbus 主站 | 读/写 | FC01 读表；FC05/0F **唯一写表来源** |
| 界面勾选框 | **只读显示** | 镜像主站写入结果，不可点击改写 |
| 输出端口 C0～CN-1 | 读出 | 主站写入后立即 `dataUpdated`，供本图使用 |
| OSC `/C0`～`/CN-1` | **仅反馈** | 主站写入后 `stateFeedBack`；忽略 `/Cn` Command |

本节点**不主动轮询**；读写节奏完全由主站发起。

线圈 **数量**、**地址基址（0/1 基）**、**起始地址** 可配置（默认 16 路、PDU 起始 `1`）。

### 输入

| 端口 | 类型 | 说明 |
|------|------|------|
| HOST | VariableData | 监听地址（如 `0.0.0.0`） |
| PORT | VariableData | 监听端口（默认 `50001`） |
| ID | VariableData | Modbus 从站单元 ID（默认 `1`） |

### 输出

| 端口 | 类型 | 说明 |
|------|------|------|
| C0 [addr]… | VariableData | 当前线圈状态（主站写入后的镜像） |

## 3. 界面与属性

- **监听地址 / 端口 / 从站 ID**：TCP 从机参数（默认 `0.0.0.0:50001`，ID `1`）。
- **数量 / 地址基址 / 起始地址**：配置线圈映射；协议匹配始终按 PDU。
- **监听状态**：绿=监听中，红=未监听。
- **线圈状态(只读)**：禁用勾选框，仅显示主站写入结果。

外部控制（可写配置）：`/host`、`/port`、`/serverId`、`/coilCount`、`/addressBase`、`/coilStartAddress`；`/listening` 为只读状态反馈；`/C0`～`/CN-1` 仅状态反馈，Command 写无效（详见第 4 段）。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/host` | 可写 | 设置监听地址，变更即重启监听 |
| `/port` | 可写 | 设置监听端口（默认 50001），变更即重启监听 |
| `/serverId` | 可写 | 设置从站 Unit ID（默认 1；不重启监听，后续请求按新 ID 过滤） |
| `/coilCount` | 可写 | 设置线圈数量（增删输出端口并重配映射） |
| `/addressBase` | 可写 | 设置地址基址（0=PDU / 1=1 基显示；只影响显示与匹配区间换算） |
| `/coilStartAddress` | 可写 | 设置起始地址（按当前基址显示值，内部存 PDU） |
| `/listening` | 只读 | 监听状态反馈（由 TcpServer `isReady` 回调驱动；`onGlobalEvent` 无对应写分支，外部 Command 写无效） |
| `/C0`～`/CN-1` | 只读 | 主站写入后的状态镜像推送（源码**故意忽略** `/Cn` Command：状态只由主站 FC05/0F 写入） |

## 5. 行为细节

| 功能码 | 名称 | 行为 |
|--------|------|------|
| `0x01` | Read Coils | 读线圈状态并应答 |
| `0x05` | Write Single Coil | 写单线圈 → 更新表/UI/输出/OSC 反馈 |
| `0x0F` | Write Multiple Coils | 写多线圈 → 同上 |

- Unit ID 不匹配则**忽略该帧（不回包）**。
- 写单线圈：`0xFF00` = ON，`0x0000` = OFF。
- 协议层始终 **PDU（0 基）**；默认起始 PDU **1**。

### 同步逻辑

**原则：只有主站可以改线圈表；本节点把结果镜像给界面与图。**

### 主站读（FC `0x01`）

按当前状态表应答；不改变本地状态。

### 主站写（FC `0x05` / `0x0F`）

1. 校验地址与数值。  
2. 写入状态表。  
3. 刷新只读勾选、输出端口、OSC 反馈。  
4. 回写成功应答。

### 与 Master 节点配合

| 角色 | 行为 |
|------|------|
| 本节点（Slave） | 被动应答；状态仅由主站写入 |
| ModBus Coil Controller（Master） | 以主机期望为准写从机；空闲读回纠偏 |

## 6. 使用说明与典型接法

1. 确认状态为绿色「监听中」。  
2. 设置数量、基址、起始地址。  
3. 主站连接本机端口（默认 **50001**），按配置读写线圈。  
4. 主站写入后，只读勾选与输出端口同步更新；本图从输出端口取状态。

## 7. 常见问题（可选）

- 修改数量会增删输出端口，超出范围的连线会丢失。  
- 工程不持久化线圈状态（纯被控，重开后默认 OFF，等主站再写）。  
- `coilStartAddress` 按 **PDU** 存盘。
