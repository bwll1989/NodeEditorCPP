# Audio List Decoder

## 1. 节点说明

独立插件：按播放列表顺序解码。每行可改文件与增益；右上角「添加」新增一条。Index 仅表示 PLAY 目标序号。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 4 | 是 | 1 | 不限 | VariableData | 末端口为 LIST_LOOP（列表循环）；PLAY/INDEX/LOOP/LIST_LOOP 均为控制口 |
| 输出 | 2 | 是 | 1 | 不限 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



**输入（4）：** PLAY / INDEX / LOOP / LIST_LOOP  
**输出（可编辑）：** CH 0、CH 1…

| 输入 | 行为 |
|------|------|
| PLAY | **bool**：`true` 按 Index 播放，`false` 停止 |
| INDEX | 只设定 PLAY 目标序号 |
| LOOP | 单曲循环 |
| LIST_LOOP | 列表循环 |

## 3. 界面与属性

### QListView

| 区域 | 说明 |
|------|------|
| Index / Play·Stop / 循环 | 单一勾选按钮：勾选=播放，取消=停止 |
| 列表标题行 | 左侧「播放列表」，右侧「添加」 |
| 曲目行 | `↑` `↓` + 文件选择（…）+ 增益 dB + `×`；双击播放（不改 Index） |

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/play` | 读写 | `true` 按 Index 播放 / `false` 停止；实际播放状态由引擎回发后自动推送反馈。 |
| `/index` | 读写 | PLAY 目标序号（仅设定，不触发播放）；越界自动钳制到列表范围。 |
| `/loop` | 读写 | 单曲循环；开启时自动关闭列表循环。 |
| `/listLoop` | 读写 | 列表循环；开启时自动关闭单曲循环。 |

4 个地址均注册了带属性 member 的绑定并订阅了 Command：模型就绪时各推送一次初始值，此后属性每次变化（界面、端口或外部写入）自动推送反馈。播放列表内容（文件、增益）没有 OSC 地址，只能在面板编辑。

## 5. 行为细节

- Index 仅供 PLAY 定位：列表编辑（增删、上下移）与自动切曲都不会改它，仅当 Index 超出列表范围时钳制到 `0 … count-1`（空列表恒为 0）。
- INDEX 端口只设定目标序号、不触发播放；取值支持 `{index: n}` 键或 default 数值，布尔值忽略。
- LOOP 与 LIST_LOOP 互斥：开启一个会自动关闭另一个；两者都关时顺序播完即停。
- 双击列表行直接播放该行，但**不**改 Index；播放按钮按 Index 播放。
- 引擎播放失败（如文件缺失）时按钮自动复位为停止；列表播完发 `playlistFinished`，播放状态归 false。
- 真值解析支持布尔、非 0 整数、字符串 `"true"`/`"1"`。
- 输出端口 `CH 0…` 对应解码器各音频输出缓冲，端口连接策略输入输出均为 Many；控件面板在右侧属性面板（`WidgetEmbeddable=false`），节点高度可调，端口可编辑。
- 持久化：`values` 子对象含 `index` / `loop` / `listLoop` / `playing` 与 `playlist` 数组（每项 `{path, gainDb}`，存媒体库相对路径）。加载时先恢复列表，loop/listLoop 键存在才应用；`playing=true` 且列表非空则自动按 Index 播放，否则仅预备该序号不发声。

## 6. 使用说明与典型接法

基本用法：将上游节点输出接入本节点输入端口，本节点输出端口连接下游节点的对应输入。
