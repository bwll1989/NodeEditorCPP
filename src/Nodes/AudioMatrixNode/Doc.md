# Audio Matrix
本插件（`Audio` 分类，`AudioMatrixNode.node`）包含两个节点：**Audio Matrix**（增益混音矩阵）与 **Audio Router**（纯路由）。两者端口结构相同（IN1～INn / OUT1～OUTm，均端口可编辑），都用 patchbay 交叉点矩阵界面操作；差异在于交叉点语义——Matrix 是可拖拽的 dB 增益混音，Router 是通/断纯路由。需要把多路输入按电平混合到多路输出时用 Audio Matrix，只需要切换/分配通路（每输出最多一路）时用 Audio Router。

## 1. 节点说明

> ⚠️ **版本要求**：本节点为 **Advance（进阶版）** 功能，需有效授权后才能加载使用。

可配置通道数的音频混音矩阵：将多路输入按增益矩阵加权混合到多路输出。**行数 = In 端口数，列数 = Out 端口数**，矩阵尺寸随端口数自动伸缩；每个交叉点是一个可拖拽的 dB 增益，同一列（输出）可叠加多路输入混音，一路输入也可扇出到多列。

典型用途：多声道分配与混音（如把立体声素材分发到 8 声道扩声、按比例混合多路音源）、舞台监听混音、通道级应急切换（把增益拉到 -60 即等效断开该路）。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 8 | 是 | 1 | 不限 | AudioData | 无 |
| 输出 | 8 | 是 | 1 | 不限 | AudioData | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 端口明细

| 端口 | 名称 | 数据类型 | 必接 | 说明 |
|------|------|----------|------|------|
| 输入 0…n-1 | IN1…INn | AudioData | 否 | 参与混音的音频源（共享环形缓冲直传）。断开时：该路从所有输出的混音集合中移除，其余输入继续混音；全部断开时所有输出静音 |
| 输出 0…m-1 | OUT1…OUTm | AudioData | — | 混音结果 `OUTj = Σᵢ 10^(dB(i,j)/20) × INi`。列内所有增益 ≤ -60 dB（线性 ≤ 0.001）或无贡献者时该输出无帧（静音） |

端口命名从 1 开始（IN1/OUT1 对应索引 0）。增删端口后矩阵行列自动跟随（约 100 ms 内对齐）：扩容时新增交叉点默认 -60 dB（静音），既有增益保留；缩容时超出范围的增益丢弃。

## 3. 界面与属性

内嵌界面为**经典 patchbay 增益矩阵**（不嵌入节点体，双击节点打开；节点体可缩放）：

- **轴标签**：左侧竖排 IN1…INn（行 = 输入），顶部横排 OUT1…OUTm（列 = 输出）。
- **交叉点**：每个格子为可拖拽 dB 值（范围 **-60 ～ +20 dB**，1 位小数）；按住上下拖动调节，提示实时显示 dB 值。增益转线性按 `10^(dB/20)` 计算。
- **左上角「⋯」菜单**：
  - `1:1 直通`：对角线 0 dB、其余 -60 dB；
  - `全部静音`：所有交叉点 -60 dB。

本节点无可配置 Q_PROPERTY 属性，无额外外部控制地址（音频数据走端口，不经 OSC 传帧）。

## 4. 外部控制（OSC 地址）

本节点未注册任何专属 OSC 地址（源码无 `Q_PROPERTY` 外部属性、无 `registerExternalBinding` 调用）；矩阵增益只能在本节点界面调整。

## 5. 行为细节

- **混音公式**：每个输出把自己列上所有"活跃且增益高于静音下限（-60 dB）"的输入按线性增益叠加；增益恰为 -60 dB 等效静音（不参与运算）。
- **追帧策略**：工作线程独立音频循环（实时优先级守护，48 kHz 帧尺寸）；各输出口只跟随对自己有贡献的输入追帧，一次唤醒最多处理 2 帧，落后时钟 2 帧以上时最多追 8 帧；同一时间戳连续两次取不到帧才判缺失，避免抖动。
- **输入断线**：该输入立即退出所有混音集合（等价于增益置 -60），其余输入的混音不中断。
- **端口与矩阵联动**：端口数由框架直接修改，节点以 100 ms 轮询对齐矩阵尺寸并重建输出缓冲，随后向所有输出口重新广播数据。
- **持久化**：`save()/load()` 保存矩阵为 `matrix { rows, cols, data[] }`（dB 值按行展开）；端口数由工程 `.flow` 的 `input-count`/`output-count` 恢复，矩阵尺寸随后自动对齐。

## 6. 使用说明与典型接法

1. 从面板 **Audio → Audio Matrix** 创建（默认 8 进 8 出，输出为静音矩阵）。
2. 按需用端口编辑区加减 In/Out（最少各 1 路）。
3. 点「⋯」选 `1:1 直通` 获得对角线直通，或直接拖动交叉点设定增益。
4. 将 OUTj 接到 Audio Device Out / 录制 / 下级处理节点。
5. 保存工程后矩阵增益与端口数一并恢复。

示例：IN1（音乐）、IN2（话筒）混到 OUT1：拖 `IN1×OUT1` 至 0 dB、`IN2×OUT1` 至 -6 dB；OUT2 仅监听音乐：`IN1×OUT2` = 0 dB，`IN2×OUT2` = -60 dB。

# Audio Router

## 1. 节点说明

纯路由 patchbay 节点：只决定哪路 In 接到哪路 Out，**不做增益混音**。每个输出最多选一路输入（同列切换自动断开旧连接），一路输入可扇出到多路输出。与 Audio Matrix 同插件、同端口结构；需要按电平混合时用 Audio Matrix，本节点适合信号源切换、通路分配、备份源倒换等场景。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 8 | 是 | 1 | 不限 | AudioData | 无 |
| 输出 | 8 | 是 | 1 | 不限 | AudioData | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 端口明细

| 端口 | 名称 | 数据类型 | 必接 | 说明 |
|------|------|----------|------|------|
| 输入 0…n-1 | IN1…INn | AudioData | 否 | 路由源。断开时：以它为源的输出变为无路由（静音），其余输出不受影响 |
| 输出 0…m-1 | OUT1…OUTm | AudioData | — | 输出所选输入的原始帧（无增益、不混音）。路由为「未接」（-1）时输出静音 |

端口命名从 1 开始（IN1/OUT1 对应索引 0）。增删端口后路由表自动跟随：缩容时超出范围的路由丢弃，其余保留；全新建节点默认对角线 1:1 接通。

## 3. 界面与属性

内嵌界面为**二进制路由矩阵**（行 = IN，列 = OUT，不嵌入节点体，双击节点打开）：

- **交叉点**：单选按钮，点击接通（高亮蓝色），再点断开；**同列切换自动取消旧连接**（每输出最多一路）。
- **左上角「⋯」菜单**：
  - `1:1 直通`：对角线接通，其余断开；
  - `全部断开`：清除所有路由。

本节点无可配置 Q_PROPERTY 属性，无额外外部控制地址（路由操作在界面完成，音频数据走端口）。

## 4. 外部控制（OSC 地址）

本节点未注册任何专属 OSC 地址（源码无 `Q_PROPERTY` 外部属性、无 `registerExternalBinding` 调用）；路由只能在本节点界面调整。

## 5. 行为细节

- **路由语义**：内部为每输出一个源索引映射（-1 = 未接）；输出帧直接取自所选输入的环形缓冲，不重采样、不加增益。
- **输出静音条件**：路由为 -1、所选输入未连接或不活跃——该输出停止产出帧（下游视为静音），其余输出继续。
- **追帧策略**：与 Audio Matrix 相同的独立音频循环（实时优先级、48 kHz 帧尺寸、每唤醒最多 2 帧、落后时最多追 8 帧、同戳缺帧 defer 一次再判缺失）。
- **端口与路由联动**：端口数变化由 100 ms 轮询对齐，路由表按重叠区域保留并重建输出缓冲，随后向所有输出口重新广播。
- **持久化**：`save()/load()` 保存路由为 `routing { rows, cols, map[] }`（每输出对应的输入索引，-1 = 未接）；端口数由工程 `.flow` 恢复。

## 6. 使用说明与典型接法

1. 从面板 **Audio → Audio Router** 创建（默认 8 进 8 出、对角线 1:1）。
2. 按需加减 In/Out 端口（最少各 1 路）。
3. 点击交叉点切换路由；「⋯」菜单可一键 `1:1 直通` 或 `全部断开`。
4. 未接路由的输出为静音；切换路由时输出无缝跟随新源（同一时钟追帧）。

## 7. 与 Matrix 的区别

| | Audio Matrix | Audio Router |
|---|---|---|
| 交叉点 | 可拖拽 dB 增益（-60～+20） | 通 / 断 |
| 同列（输出） | 可多路输入叠加混音 | 最多一路 |
| 新建默认 | 全部 -60 dB（静音） | 对角线 1:1 接通 |
| 输入断线 | 退出混音集合，其余输入继续 | 该输出转为无路由（静音） |
| 用途 | 混音 / 分配电平 | 切换 / 分配通路 |
