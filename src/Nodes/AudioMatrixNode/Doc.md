# Audio Matrix / Audio Router

本插件包含两个节点：**Audio Matrix**（增益混音矩阵）与 **Audio Router**（纯路由）。

---

## Audio Matrix

### 1. 节点说明

可配置通道数的音频路由矩阵：将多路输入按界面增益矩阵混到多路输出。**行数 = In 端口数，列数 = Out 端口数**；通过节点端口编辑增减通道。

### 2. 端口说明

- **IN1**～**INn**（AudioData）：n 路音频输入（端口可编辑）。
- **OUT1**～**OUTm**（AudioData）：m 路音频输出（端口可编辑）。

### 3. 界面说明

经典 patchbay：左上角「⋯」菜单（`1:1 直通` / `全部静音`），交叉点为可拖拽 dB 增益。

### 4. 使用说明

1. 编辑 In/Out 端口数量。
2. 拖动交叉点调节路由增益。
3. OUTm 接到声卡或下级处理。

---

## Audio Router

### 1. 节点说明

与矩阵同布局的**纯路由**节点：只决定哪路 In 接到哪路 Out，不做增益混音。每列（每个输出）最多选一路输入；一路输入可扇出到多路输出。

### 2. 端口说明

- **IN1**～**INn**（AudioData）：n 路音频输入（端口可编辑）。
- **OUT1**～**OUTm**（AudioData）：m 路音频输出（端口可编辑）。

### 3. 界面说明

- **左上角**：`1:1 直通` / `全部断开`。
- **交叉点**：点击接通（高亮），再点断开；同列切换会自动取消旧连接。
- 默认对角线 1:1 接通。

### 4. 使用说明

1. 增减 In/Out 端口数。
2. 点击交叉点建立/取消路由。
3. 未连接的输出输出静音。

### 5. 与 Matrix 的区别

| | Audio Matrix | Audio Router |
|---|---|---|
| 交叉点 | dB 增益 | 通 / 断 |
| 同列 | 可多路混音 | 最多一路 |
| 用途 | 混音 / 分配电平 | 切换 / 分配通路 |
