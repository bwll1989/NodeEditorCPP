# Audio Matrix

## 1. 节点说明

可配置通道数的音频路由矩阵：将多路输入按界面增益矩阵混到多路输出。**行数 = In 端口数，列数 = Out 端口数**；通过节点端口编辑增减通道（无硬上限，过大时界面控件数量会先成为瓶颈）。

## 2. 端口说明

### 输入

- **IN1**～**INn**（AudioData）：n 路音频输入（端口可编辑）。

### 输出

- **OUT1**～**OUTm**（AudioData）：m 路音频输出（端口可编辑）。

## 3. 界面说明

经典 patchbay 布局：

- **左上角**：扁平「⋯」菜单——`1:1 直通` / `全部静音`。
- **顶栏**：竖排输出名（out 0 …），与矩阵列对齐。
- **左侧**：横排输入名（in 0 …），与矩阵行对齐。
- **矩阵格**：浅紫→靛蓝热力色；静音为浅底描边；节点拉大后格内显示 dB。

## 4. 使用说明

1. 在节点属性里编辑 In/Out 端口数量（或用端口旁 +/-）。
2. 将各音源接到 INn。
3. 拖动交叉点调节路由增益（或点左上角「⋯」选直通 / 全部静音）。
4. 将 OUTm 接到声卡或下级处理。

## 5. 示例

4 路播放器 + 2 路话筒 → Audio Matrix → OUT1/2 主 LR，OUT3 耳返。
