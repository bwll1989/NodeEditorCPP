# Data Info

## 1. 节点说明

Data Info 用于**查看**流经节点的数据结构：在独立窗口中以树形方式展示 VariableData 的字段，支持增量更新，便于调试数据流、确认 OSC/脚本输出格式。

- 输出 0 透传原数据，View 窗口展示全部字段。
- 输入为 ImageData 等非 VariableData 类型时无法解析（输出为空）；请使用 Image Display 等专用节点查看图像。

（原 Image Info 节点功能已合并至本节点。）

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 1 | 否 | 1 | 1 | — | 无 |
| 输出 | 1 | 否 | 1 | 1 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。

### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | DATA | VariableData | 待查看的数据（仅接受 VariableData） |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | DATA | VariableData | 原样透传输入数据 |

## 3. 界面与属性

- **View** 按钮：点击后打开置顶浮动窗口「Data Info」（约 800×400），显示当前数据的属性树。
  窗口可关闭；关闭后再次点击 View 重新打开。
  数据在输入更新时会**增量刷新**浏览器内容（首次为全量构建）；浏览器懒加载、最多显示 1000 项。

节点本体仅显示按钮，不内嵌完整树视图。

## 4. 外部控制（OSC 地址）

本节点未注册任何专属 OSC 地址（源码无 `Q_PROPERTY` 外部属性、无 `registerExternalBinding` 调用）。

地址前缀：`/dataflow/{别名}/{节点ID}/…`。若节点定义了公开 Q_PROPERTY，框架会自动为其生成默认属性地址；本节点当前无此类属性。

## 5. 行为细节

- 输入更新：`asMap()` 后首次全量构建属性树，之后走增量更新（`updatePropertiesIncremental`）并刷新输出。
- 空数据（断开）保持当前显示与透传内容不变；非 VariableData 输入被忽略（输出为空）。
- 无持久化（查看器状态不写入工程）。

## 6. 使用说明与典型接法

1. 将待观察的数据流串在链路中。
2. 运行后点击 **View** 查看实时字段与值。
3. 输出 0 继续接下游，不影响原数据。

适合开发阶段；正式演出可移除或保留在旁路。

## 7. 示例

**OSC 调试：** Osc In → Data Info → Extract。在 View 中确认 `address`、`args` 等键名后再写 Extract 表达式。
