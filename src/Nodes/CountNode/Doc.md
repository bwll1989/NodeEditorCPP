# Count

## 1. 节点说明

Count 在每次输入更新时，用 **JavaScript 条件表达式**判断是否「命中」；若表达式为真，内部计数器加 1，并输出当前计数值。适合统计满足条件的次数（如某状态出现次数、达标帧数等）。

支持外部清零与读取/设置计数值。

## 2. 端口说明

### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | （默认） | VariableData | 每次更新时用表达式求值；为真则计数 +1 |

输入端口数量**可编辑**（逻辑仍使用同一输入数据）。

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | （默认） | VariableData | 当前计数值（整数） |

## 3. 界面说明

- **计数**：只读显示当前累计值（不可拖动/编辑；仍可通过外部 `/count` 读写）。
- **条件**：JS 表达式编辑框；输入数据在表达式中为全局变量 `$input`（与输入的键值映射一致）。默认示例：`$input["default"]`。
- **clear**：将计数清零。

**外部控制地址：**

- `/clear` — 发送 true 时清零（与 clear 按钮相同）
- `/count` — 读取或设置当前计数值

## 4. 使用说明

1. 在「条件」中编写返回布尔值的 JS，例如：`$input["value"] > 100`。
2. 将需要统计的数据源接到输入。
3. 输出接显示、比较或分支节点。
4. 场次切换时点击 clear 或发送 `/clear`。

表达式错误时保持原计数并输出当前值。

配置保存在 `values.expression`。

## 5. 示例

**统计超标次数：** 音频分析结果接入输入，条件 `$input["level"] > 0.8`，输出接 Data Info 或阈值报警。  
**控台复位：** 将 `/clear` 绑定复位按钮，一键清零。

# Range Map

## 1. 节点说明

Range Map 将输入数值从**输入范围**线性映射到**输出范围**。例如将 `0~1` 的浮点值映射为 `0~255` 的 DMX 亮度值。

- **标量**：映射单个 `default`。
- **向量列表**：表达式留空且 `default` 为列表时，用 Eigen 对分量做向量化线性映射，输出仍为列表。
- 支持通过 JS 表达式从 `VariableData` 中提取待映射的数值；默认读取 `default` 键。

## 2. 端口说明

### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | INPUT | VariableData | 待映射的数据源 |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | OUTPUT | VariableData | 映射后的数值（标量或同长度列表） |

## 3. 界面说明

- **输入最小 / 输入最大**：源数值范围，默认 `0` ~ `1`
- **输出最小 / 输出最大**：目标数值范围，默认 `0` ~ `255`
- **输入值**：JS 表达式，留空则使用 `default` 键；示例：`$input["level"]`
- **限制在输出范围内**：开启后超出输入范围的值会被钳制到输出范围边界

**外部控制地址：**

- `/inMin`、`/inMax`、`/outMin`、`/outMax` — 设置映射范围
- `/clamp` — 设置是否钳制（true/false）

## 4. 使用说明

1. 将浮点数据源（如 LFO、音频分析）接到输入。
2. 设置输入范围与输出范围，例如 `0~1` → `0~255`。
3. 输出接 OSC Out、DMX 或条件判断节点。

映射公式：`output = outMin + (value - inMin) / (inMax - inMin) * (outMax - outMin)`

配置保存在 `values.inMin`、`values.inMax`、`values.outMin`、`values.outMax`、`values.clamp`、`values.expression`。

## 5. 示例

**DMX 亮度映射：** LFO 输出 `0~1` 接入 Range Map，输出范围 `0~255`，结果接 DMX Device。  
**传感器归一化：** 原始 ADC `0~1023` 映射到 `0~1`，输入范围设为 `0` / `1023`，输出范围 `0` / `1`。  
**颜色/向量：** Color 或 Vec Source（`default` 为列表）接入，表达式留空，各分量按同一范围映射。

# Feedback

## 1. 节点说明

Feedback 在每次输入更新时**保存上一帧数据**，并用两个输出端口分别给出：

- **CURRENT**：这一次刚收到的输入
- **PREVIOUS**：上一次收到的输入

适合做差值、平滑、状态对比，或把上一帧结果接到后续计算。首次收到数据时 PREVIOUS 为空。

## 2. 端口说明

### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | INPUT | VariableData | 当前帧数据；写入后会把原 CURRENT 挪到 PREVIOUS |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | CURRENT | VariableData | 这一次的输入快照 |
| 1 | PREVIOUS | VariableData | 上一次的输入快照 |

## 3. 界面说明

无参数界面。节点仅透传并缓存数据。

## 4. 使用说明

1. 将数据源接到 INPUT。
2. CURRENT 接需要「当前值」的节点。
3. PREVIOUS 接需要「上一帧」的节点（如相减、比较、混音）。

每次 `setInData` 先把当前值存为上一帧，再写入新值，然后同时更新两个输出。

## 5. 示例

**求变化量：** 传感器接到 Feedback，CURRENT 与 PREVIOUS 再接入减法节点，得到相邻两次采样的差值。  
**一阶平滑：** 把 PREVIOUS 与当前源按权重混合后再写回后续链路，用上一帧结果做平滑。

# Log Out

## 1. 节点说明

Log Out 用完整 **JavaScript 表达式**生成消息，打印到终端，并从 **OUTPUT** 输出。实例化后即启用。输入以全局变量 `$input` 注入（与 Extract 一致），也支持用顶层键名直接访问。

## 2. 端口说明

### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | VALUE | VariableData | 注入为 `$input` 的数据源 |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | OUTPUT | VariableData | `default` 为 JSON 字符串，形如 `{"timestamp":"12:42:55.855","log":"..."}` |

## 3. 界面说明

- 与 Extract 相同：整块可拉伸的文本框，内容为 **JS 表达式**。
- 默认：`$input.default`
- 拼接示例：`"设备允许错误" + $input.default + "，请检查设置"`
- 取向量元素：`$input.default[0]`
- 运算示例：`"x=" + ($input.default[0] + $input.default[1]).toFixed(2)`
- 留空则打印/输出整份 JSON。

配置保存在 `values.message`。

## 4. 使用说明

1. 将数据源接到 VALUE。
2. 在文本框中编写返回值的 JS 表达式（结果会转成字符串）。
3. OUTPUT 的 `default` 为含 `timestamp` / `log` 的 JSON 字符串；终端仍只打印 `log` 正文。

表达式错误时控制台输出错误信息，OUTPUT 消息为空字符串。

## 5. 示例

**调试字符串：** String Source → Log Out，表达式 `$input.default`。  
**带上下文的告警：** `"设备允许错误" + $input.default + "，请检查设置"`。  
**向量分量：** `$input.default[0]` 或 `` `当前输入值：${$input.default[0]}` ``（模板字符串）。
