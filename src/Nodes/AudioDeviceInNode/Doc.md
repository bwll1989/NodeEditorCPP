# Audio Device In

## 1. 节点说明

从系统音频输入设备（麦克风、线路输入等）采集音频，按声道输出 AudioData。输出端口数量可编辑（默认立体声 2 路）。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 0 | 否 | 0 | 0 | —（不可新增） | 无 |
| 输出 | 2 | 是 | 1 | 不限 | AudioData | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。

### 输入

无。

### 输出

| 端口 | 类型 | 说明 |
|------|------|------|
| CH 0 / CH 1 … | AudioData | 各输入声道（共享时间戳环形缓冲），录制时连续输出；断开下游不影响采集 |

## 3. 界面与属性

界面控件显示在右侧属性面板：设备下拉框（PortAudio 输入设备列表，可刷新）、增益拖动框。

| 属性 | 类型 | 默认值 | 取值范围 | 说明 |
|------|------|--------|----------|------|
| deviceId | int | 0 | 已枚举设备索引 | 输入设备，对应设备下拉框，OSC `/deviceId` |
| gainDb | double | 0 | dB | 采集增益，OSC `/gain` |

保存到工程：`values.deviceId`、`values.gainDb`，加载时恢复。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`（{别名} 为节点别名，{节点ID} 为节点编号）

| 地址 | 类型 | 范围 | 说明 |
|------|------|------|------|
| /gain | float | dB | 设置采集增益，等价于增益滑块 |
| /deviceId | int | 枚举索引 | 切换输入设备 |

以上地址通过 `registerExternalBinding` 注册（与内嵌控件双向绑定），并订阅全局事件总线 Command 事件。

## 5. 行为细节

- **状态与持久化**：`deviceId` / `gainDb` 保存到工程并恢复；设备切换后自动重新打开流。
- **声道数**：设备打开后按设备实际 `maxInputChannels` 采集；输出端口数可手动增删以匹配（默认 2）。
- **时序**：PortAudio 回调驱动，采集帧带系统时间戳写入各声道环形缓冲。
- **错误行为**：设备打开失败时不输出数据；节点销毁时自动停止录制。

## 6. 使用说明与典型接法

1. 属性面板选择输入设备。
2. 增益调到合适电平（避免削波）。
3. 典型链路：**Audio Device In → Audio Analysis / Audio Matrix → Audio Device Out**。

## 7. 示例

麦克风 → Audio Device In → Audio Analysis，用 LEVEL 驱动声控灯光。
