# Ranger Mini

## 1. 节点说明

AgileX **RANGER MINI 3.0** 底盘控制节点。通过 candleLight / gs_usb（WinUSB）USB-CAN 适配器，按官方 CAN 协议控制四轮四转底盘运动，并回读状态与运动反馈。

- 通信：**CAN 2.0B，500 kbps，大端（Motorola）**
- 运动指令以 **20 ms** 周期发送（协议超时约 500 ms，超时底盘会停）
- 分类：**Devices → Ranger Mini**
- 同插件另含 **Nav Controller**（AuroraS 到位姿 → 本节点运动指令），见 `NavControllerNode/Doc.md`

阿克曼模式下，日常移动通常只需 **VX + STEER**，再配合 **ENABLE** 使能即可。  
**节点间单位**：速度 **m/s**、角度 **rad**、自旋 **rad/s**、位置 **m**。  
CAN 边界再换算：VX ×1000 → mm/s；STEER/SPIN ×1000 → 0.001 rad（s）。

## 2. 硬件连接

| 项目 | 说明 |
|------|------|
| USB-CAN | candleLight / CANable 等 gs_usb 设备（设备管理器显示为 WinUSB） |
| 底盘接口 | 尾部航空扩展口：`CAN_H`、`CAN_L`（另有 46~50V 扩展电源，本节点不使用） |
| 波特率 | 固定 **500000**，节点内不可改 |

**控制权优先级：** 遥控器最高。要用本节点控制，请将遥控器 **SWB 拨到最上（指令控制）**，或关闭遥控器。急停按下时无法运动，松开后需清故障（节点有 **Clear Faults**，使能时也会自动清一次）。

## 3. 端口说明

### 输入

| 端口 | 名称 | 单位 | 说明 |
|------|------|------|------|
| 0 | VX | m/s | 车体线速度。前进为正，倒退为负。有效约 ±2.0；当 \|转向\| > 约 0.349 rad（20°）时底层限到约 ±0.7 |
| 1 | STEER | rad | 转向**内转角**（车轮转向，不是车身偏航角）。**左转为正**。阿克曼约 ±0.698，斜移约 ±1.571 |
| 2 | SPIN | rad/s | 原地自旋角速度。**逆时针为正**。仅 **Spin** 模式生效 |
| 3 | ENABLE | bool | `true`：进入 CAN 指令模式并开始 20 ms 心跳；`false`：发零速并停止心跳 |

**常用组合：**

| 运动模式 | 主要输入 | 说明 |
|----------|----------|------|
| Ackermann（默认） | VX + STEER | 前后阿克曼，日常行驶 |
| Diagonal | VX + STEER | 斜移 / 横移（转角可接近 90°） |
| Spin | SPIN | 原地旋转，VX/STEER 会被置 0 |
| Park | — | 驻车锁轮，速度指令无效 |

### 输出

| 端口 | 名称 | 说明 |
|------|------|------|
| 0 | STATUS | 系统状态 `VariableData`（来自 `0x211` / `0x291`） |
| 1 | FEEDBACK | 运动反馈 `VariableData`（来自 `0x221`） |

**STATUS 常用字段：**

| 字段 | 含义 |
|------|------|
| `control_mode` | `0` 待机 / `1` CAN 指令 / `3` 遥控 |
| `battery_v` | 电池电压（V） |
| `estop` | 是否急停 |
| `fault` | 故障位图 |
| `motion_mode` | `0` 阿克曼 / `1` 斜移 / `2` 自旋 / `3` 驻车 |
| `vehicle_state` | `0` 正常 / `2` 异常 |

**FEEDBACK 常用字段：**

| 字段 | 含义 |
|------|------|
| `linear_mps` | 实际线速度（m/s） |
| `spin_rad_s` | 实际自旋角速度（rad/s） |
| `steer_rad` | 实际转向角（rad） |

## 4. 界面说明

- **设备 / 刷新设备**：枚举本机 candleLight 设备（显示友好名，悬停可看完整路径）。
- **已连接 @500k / 未连接**：打开 / 关闭 CAN（固定 500 kbps、Normal 模式）。
- **运动模式**：阿克曼 / 斜移 / 自旋 / 驻车，对应协议 `0x141`。
- **线速度 Vx / 转角 / 自旋**：与输入端口同义，可在界面直接调。
- **清除故障**：发送清故障（含急停释放后清除），协议 `0x441`。
- **控制开启 / 控制关闭**：使能运动控制。开启时依次：切 CAN 模式 → 清故障 → 设运动模型 → 每 20 ms 发 `0x111`。
- **状态行**：简要显示模式、电压、急停。

## 5. 使用说明

1. 接通 CAN，底盘上电，确认急停已松开。
2. 添加 **Ranger Mini** 节点 → 刷新设备 → 选设备 → 点连接至绿色 **已连接 @500k**。
3. 运动模式选 **阿克曼**。
4. 设小速度（建议首次 ≤ 0.2 m/s）、转角，点 **控制开启**（或向 **ENABLE** 送 `true`）。
5. 用上游节点改 **VX / STEER**，或在界面拖动参数；底盘会持续按最新值运动。
6. 结束务必 **控制关闭**；异常时拍急停，再 **清除故障**。

**外部控制路径**（完整地址：`/dataflow/{父级别名}/{节点ID}{相对路径}`）：

| 相对路径 | 作用 |
|----------|------|
| `/deviceIndex` | USB-CAN 设备索引 |
| `/motionMode` | 运动模式 `0~3` |
| `/linearVelocity` | 线速度（m/s） |
| `/steerRadians` | 转向角（rad） |
| `/spinRate` | 自旋（rad/s） |
| `/controlEnabled` | 使能控制（bool） |

## 6. 协议摘要（实现参考）

| ID | 方向 | 作用 |
|----|------|------|
| `0x421` | 主机→底盘 | 控制模式：`0x01` = CAN 指令 |
| `0x441` | 主机→底盘 | 清故障 |
| `0x141` | 主机→底盘 | 运动模型 |
| `0x111` | 主机→底盘 | 运动指令（线速度 mm/s、自旋 0.001 rad/s、转角 0.001 rad），需周期发送 |
| `0x211` | 底盘→主机 | 系统状态 |
| `0x221` | 底盘→主机 | 运动反馈 |
| `0x291` | 底盘→主机 | 当前运动/驱动模式 |

坐标系（车体中心）：前 = +X，左 = +Y，上 = +Z。前进、左转、逆时针自旋为正。

## 7. 示例

- **阿克曼慢速前进**：Mode=Ackermann，VX=`0.15`，STEER=`0`，ENABLE=`true`。
- **边走边转**：VX=`0.3`，STEER=`0.175`（约左转 10°），ENABLE=`true`。
- **原地自旋**：Mode=Spin，SPIN=`0.5`，ENABLE=`true`。
- **图中动态控制**：数值/LFO 节点 → **VX** / **STEER**；按钮或逻辑 → **ENABLE**；**STATUS** / **FEEDBACK** → Data Info 监视。

## 8. 安全注意

- 首次在空旷场地、低速测试；身边可随时拍急停。
- 控制结束后保持 **Control OFF**，避免心跳中断前仍带速。
- 低电量（SOC 过低）时底盘可能切断驱动；注意 STATUS 中电压与急停标志。
- 本节点当前仅支持 Windows + candleLight/WinUSB 适配器。
