# Scatter Series

## 1. 节点说明

DataVisualNode 插件提供 **3D 散点**可视化节点，将输入向量映射为空间坐标并在节点面板内实时显示。无输出端口，仅作监视与调试。

| 变体 | 节点库名称 | 行为 |
|------|------------|------|
| ScatterSingle | Scatter Single | 每次更新后**移动单个点**（`updatePoint`） |
| ScatterSeries | Scatter Series | 每次更新后**追加一个新点**（`appendPoint`），形成轨迹 |

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 1 | 否 | 1 | 1 | — | 无 |
| 输出 | 0 | 否 | 0 | 0 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | XYZ | VariableData | 位置向量；从 `default` 按需截取/补 0 得到 `[x, y, z]`（短向量缺维补 0，超长截断） |

### 输出

无。

## 3. 界面与属性

节点主区域为内嵌 **3D 散点 QML 视图**，随输入实时旋转/缩放查看（具体交互以界面为准）。无额外按钮；图数据当前**不写入**工程保存（`save`/`load` 为空结构）。

## 4. 外部控制（OSC 地址）

本节点未注册任何专属 OSC 地址（源码无 `Q_PROPERTY` 外部属性、无 `registerExternalBinding` 调用）。

地址前缀：`/dataflow/{别名}/{节点ID}/…`。若节点定义了公开 Q_PROPERTY，框架会自动为其生成默认属性地址；本节点当前无此类属性。

## 5. 行为细节

- 输入更新：从 `default` 按需截取/补 0 得到 `[x, y, z]`，跨线程经 `QMetaObject::invokeMethod` 调用 QML `appendPoint` 追加散点。
- 空数据（断开）不追加新点。
- 图数据当前**不写入**工程保存（`save`/`load` 为空结构）。

## 6. 使用说明与典型接法

1. 选择 Scatter Single（单点跟随）或 Scatter Series（留轨迹）。
2. 将三维向量源（如 Vec Source Size=3、LocationProto POS）接到 **XYZ**。
3. 用于观察 LFO、传感器或脚本输出的三维关系。

Scatter Series 长时间运行会累积大量点，注意性能与清晰度。

## 7. 示例

**单点跟踪：** Scatter Single，接陀螺仪或模拟向量，观察当前姿态点。
**轨迹记录：** Scatter Series，接无人机或鼠标三维坐标，回放运动路径。

# Scatter Single

## 1. 节点说明

数据可视化插件的一员：将输入向量映射为 3D 空间坐标，在内嵌 QML 视图中实时显示。每次更新后**移动单个点**，始终只显示最新位置，不累积轨迹；需要保留历史轨迹时用 **Scatter Series**。图数据不写入工程保存。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 1 | 否 | 1 | 1 | — | 无 |
| 输出 | 0 | 否 | 0 | 0 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 类型 | 必接 | 说明 |
|------|------|------|------|
| XYZ | VariableData | 否 | 位置向量 float[3]（m 或自定义单位，仅显示）；断开时：保持最后状态 |

### 输出
无。

## 3. 界面与属性

本节点无可配置属性。内嵌 3D 散点 QML 视图，随输入实时刷新。

## 4. 外部控制（OSC 地址）

本节点未注册任何专属 OSC 地址（源码无 `Q_PROPERTY` 外部属性、无 `registerExternalBinding` 调用）。

地址前缀：`/dataflow/{别名}/{节点ID}/…`。若节点定义了公开 Q_PROPERTY，框架会自动为其生成默认属性地址；本节点当前无此类属性。

## 5. 行为细节

- 输入更新：从 `default` 按需截取/补 0 得到 `[x, y, z]`，跨线程调用 QML `updatePoint` 移动单点。
- 断开输入时保持最后状态；图数据不写入工程保存。

## 6. 使用说明与典型接法

将三维向量源（如 Vec Source Size=3、LocationProto POS）接到 **XYZ** 口，观察最新位置点；需要轨迹时改用 Scatter Series。

## 7. 示例

**姿态监视：** 陀螺仪/模拟向量 → Scatter Single，实时观察当前姿态点。
