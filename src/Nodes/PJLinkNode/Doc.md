# PJLink

## 1. 节点说明

通过 **PJLink** 协议（TCP）控制网络投影仪：开关机、静音/取消静音、自定义命令；支持密码认证与连接状态查询。连接后约每 5 秒查询电源状态作为心跳。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 3 | 否 | 3 | 3 | — | 无 |
| 输出 | 1 | 否 | 1 | 1 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 类型 | 说明 |
|------|------|------|
| POWER | VariableData | `true` 开机，`false` 关机 |
| MUTE | VariableData | `true` 静音，`false` 取消静音 |
| CUSTOM | VariableData | `true` 时发送界面中的自定义命令 |

### 输出

| 端口 | 类型 | 说明 |
|------|------|------|
| STATUS | VariableData | 连接状态或设备返回的文本响应 |

## 3. 界面与属性

控件面板（`WidgetEmbeddable=false`，显示在右侧属性面板，不嵌入节点体）：

| 控件 | 含义 |
|------|------|
| 主机 / 端口 / 密码 | 投影仪 PJLink 地址（默认主机 `192.168.0.10`；默认端口常见为 4352，以设备为准） |
| 开机 / 关机 / 静音开 / 静音关 | 快捷命令按钮 |
| 自定义命令 | 如 `POWR 1` 或 `AVMT 30`（指令与参数用空格分隔）；编辑完成即发送 |
| 连接状态 | 是否已连接并完成认证 |

可外部控制的属性（Q_PROPERTY）：`host`、`port`、`password`、`customCommand`、`connected`（只读状态）、`powerOn` / `powerOff` / `muteOn` / `muteOff` / `sendCustom`（均为脉冲属性，触发后自动复位）。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/host` | 读写 | 投影仪 IP（修改后立即重连） |
| `/port` | 读写 | PJLink 端口（修改后立即重连） |
| `/password` | 读写 | PJLink 密码（修改后立即重连） |
| `/customCommand` | 读写 | 自定义命令文本（仅更新缓存，不发送） |
| `/powerOn` | 命令 | 开机（`POWR 1`；payload 缺省或 true 时执行） |
| `/powerOff` | 命令 | 关机（`POWR 0`） |
| `/muteOn` | 命令 | 静音（`AVMT 31`） |
| `/muteOff` | 命令 | 取消静音（`AVMT 30`） |
| `/custom` | 命令 | payload 为字符串时直接作为自定义命令发送；否则 true 触发发送界面命令 |
| `/connect` | 只读状态 | 连接状态（member 绑定未订阅 Command，外部写无效） |

## 5. 行为细节

- **连接与认证**：构造时按当前 host/port 自动连接；host、port、password 任一变化都会重置认证状态并重连。收到 `PJLINK <版本> <认证信息>` 应答后处理认证：`0` 表示无需认证；8 位随机串表示需要密码，节点计算 `MD5(随机串 + 密码)` 作为认证哈希；`ERRA` 表示密码错误。
- **指令发送**：未连接或未认证时指令被丢弃。无密码时格式为 `%1<指令> <参数>\r`；有密码时在指令前附加 MD5 哈希。
- **命令脉冲**：powerOn/powerOff/muteOn/muteOff/sendCustom 均为脉冲属性（true 触发发送后立即复位 false）。
- **心跳**：连接成功后每 5 秒发送一次 `POWR ?` 电源查询（需已认证），兼作用途保活；断开时停止心跳并将节点标记为校验错误「连接错误」。
- **STATUS 输出**：连接状态变化时输出布尔值；每次收到设备应答时输出应答文本（最后一次为准）。
- **已知缺陷（源码如实记录）**：`setInData` 中 MUTE 分支缺少 `break`，会贯穿到 CUSTOM 分支——MUTE 端口收到数据时，若值为 true，除静音外还会额外触发一次自定义命令发送。
- **连接策略**：所有端口均为 Many。
- **持久化**：`save()` 将 `IP`、`Port`、`Password`、`CustomCommand` 写入 `values.*`（键名首字母大写）。
- **资源清理**：析构时停止心跳并断开 TCP 连接。

## 6. 使用说明与典型接法

1. 填写投影仪 IP、端口与 PJLink 密码（若需要）。
2. 等待连接与认证成功后再发控制命令。
3. 自定义命令格式：`指令 参数`，例如 `INPT HDMI1`。
4. 输入端口适合接场景触发或定时节点。

## 7. 示例

场景「会议开始」→ POWER 输入 `true` 开机；场景「结束」→ POWER `false`；STATUS 接日志记录投影仪应答。
