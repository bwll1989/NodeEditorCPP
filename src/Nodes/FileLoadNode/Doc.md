**File Load 插件**

从媒体库加载文件并输出数据。当前注册节点：**Image File**、**JSON File**、**INI File**（CSV 节点在 PluginDefinition.cpp 中注册已注释，不可用）。

三个节点共用同一套框架：`file` Q_PROPERTY + `/file` OSC 绑定 + 媒体库选择下拉框，路径一律为媒体库根目录（`MEDIA_LIBRARY_STORAGE_DIR`）下的相对路径。

---

# Image File

## 1. 节点说明

从媒体库加载一张图片，解码后上传 GPU 纹理，以 ImageData 持续输出。静态源节点：只在加载时写入一帧，不随系统时钟重复推送。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 0 | 否 | 0 | 0 | — | — |
| 输出 | 1 | 否 | 1 | 1 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。

### 输入

无。

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | （默认） | ImageData | 加载的图像（GPU 纹理 + CPU 副本，供显示或 OpenCV 节点使用） |

## 3. 界面与属性

- **文件选择下拉框**（媒体库「图片」分类；`WidgetEmbeddable=true`，控件嵌入节点体内），变更后自动重新加载。
- Q_PROPERTY：`file`（媒体库相对路径）。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/file` | 读/写 | 切换文件（Command 事件，payload 为媒体库相对路径字符串，写空则清空输出） |

## 5. 行为细节

- **发布策略**：解码 + GPU 上传完成后向输出环形缓冲写入**一帧**（时间戳取当前全局帧号，去重推送）；之后不随 tick 重复 push、不 emit dataUpdated——下游显示/处理节点订阅 TimestampGenerator 后按系统时钟自行取最新帧。
- **路径解析**：实际路径 = 媒体库根目录 + `/` + 所选文件名；文件名先 trim，重复设置同名文件不触发重载。
- **错误处理**：文件名为空、打开/解码失败、纹理上传失败时进入 Error 校验状态（"cannot open file"/"cannot upload texture"），清空缓存与环形缓冲，不清空输出端口数据——下游在下一 tick 发现缓冲无有效帧自行清屏。
- **持久化**：文件路径存于 JSON 顶层 `path` 键（非 `values`），加载时经 `setFile` 触发重载。

## 6. 使用说明与典型接法

选择媒体库中的图片作为静态底图、角标、遮罩素材；OSC `/file` 可在演出中切换素材。输出可同时接显示节点与处理节点。

## 7. 示例

Image File（logo.png）→ Image Layout，作为固定角标；运行中向 `/file` 发送新路径即可热切换素材。

# JSON File

## 1. 节点说明

从媒体库读取 JSON 文件并解析，以 VariableData 输出（对象/数组结构）。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 0 | 否 | 0 | 0 | — | — |
| 输出 | 1 | 否 | 1 | 1 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。

### 输入

无。

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | （默认） | VariableData | JSON 解析结果（结构见行为细节） |

## 3. 界面与属性

- **文件选择下拉框**（媒体库「文档」分类；`WidgetEmbeddable=true`，控件嵌入节点体内），变更后自动重新加载。
- Q_PROPERTY：`file`（媒体库相对路径）。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/file` | 读/写 | 切换文件（Command 事件，payload 为媒体库相对路径字符串） |

## 5. 行为细节

- **解析规则**：根为对象 → 直接以该对象构造 VariableData；根为数组 → 存入默认键 `default`（QVariantList），下游经 `asMap()["default"]` 取数组；其他根类型 → 空对象。
- **错误处理**：文件名为空时仅清空输出（emit dataUpdated）；打开失败（"cannot open file"）或解析失败（"parse error: …"）进入 Error 校验状态并清空输出。
- **成功路径**：进入 Valid 状态并 emit dataUpdated(0) 触发下游刷新。
- **持久化**：文件路径存于 JSON 顶层 `path` 键，加载时自动重读文件。

## 6. 使用说明与典型接法

选定 JSON 后供 Extract、JS Script 等节点读取节目配置、点位表等静态数据。

## 7. 示例

JSON File（show.json）→ Extract → Inject，按配置触发场景。

# INI File

## 1. 节点说明

从媒体库读取 INI 配置文件（QSettings/IniFormat 解析），输出嵌套 + 扁平化两种结构的 VariableData。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 0 | 否 | 0 | 0 | — | — |
| 输出 | 1 | 否 | 1 | 1 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。

### 输入

无。

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | （默认） | VariableData | INI 解析结果（结构见行为细节） |

## 3. 界面与属性

- **文件选择下拉框**（媒体库「文档」分类；`WidgetEmbeddable=true`，控件嵌入节点体内），变更后自动重新加载。
- Q_PROPERTY：`file`（媒体库相对路径）。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/file` | 读/写 | 切换文件（Command 事件，payload 为媒体库相对路径字符串，写空则清空输出） |

## 5. 行为细节

- **输出结构**（三种并存）：
  - `global`：根键（无分组）键值对（QVariantMap），无根键时不含该键；
  - 每个 `[分组]`：以分组名为键，内容为该组键值对（QVariantMap）；
  - `default`：**扁平化映射**——根键为 `key`，分组键为 `group.key`，便于 Extract 直接取 `default["device.ip"]`。
- **错误处理**：文件名空 → 仅清空输出；文件不存在 → Error 状态（"file not exists"）并清空输出。
- **值类型**：经 QSettings 读取，均为字符串形式（QSettings 不做类型推断），下游比较时注意类型。
- **持久化**：文件路径存于 JSON 顶层 `path` 键，加载时自动重读文件。

## 6. 使用说明与典型接法

用于加载设备参数、IP/端口等静态配置；下游用 Extract 从 `default` 扁平映射取值最方便。

## 7. 示例

INI File → Extract `default["device.ip"]` → TCP Client 主机地址。
