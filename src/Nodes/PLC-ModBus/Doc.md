# PLC_ModBus

## 1. 节点说明

> ⚠️ **版本要求**：本节点为 **Advance（进阶版）** 功能，需有效授权后才能加载使用。

通过 **Modbus TCP** 读写 PLC 保持寄存器，实现最多 32 路 **Z**（控制输出）与 **S**（状态反馈）。支持 **Beckhoff**、**Siemens** 两种地址映射；Z 为脉冲式写入（约 500 ms 后自动复位），S 由定时轮询更新。

## 3. 界面与属性

控件面板（`WidgetEmbeddable=false`，显示在右侧属性面板，不嵌入节点体）：

| 控件 | 含义 |
|------|------|
| 主机 / 端口 / 从站 ID | Modbus TCP 连接（默认 `127.0.0.1:502`，从站 1） |
| PLC 类型下拉 | 0 = Beckhoff、1 = Siemens，切换后更新 Z/S 标签与寄存器基址 |
| Z 0～31 控制按钮 | 切换触发（连接断开时禁用） |
| S 0～31 状态指示 | 只读复选框，随轮询更新 |
| 连接状态标签 | 是否在线 |

可外部控制的属性（Q_PROPERTY）：`host`、`port`、`serverId`、`plcType`、`connected`（只读）。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/host` | 读写 | PLC IP（修改后立即重连） |
| `/port` | 读写 | Modbus TCP 端口（修改后立即重连） |
| `/serverId` | 读写 | 从站单元 ID |
| `/plcType` | 读写 | PLC 类型索引（0=Beckhoff，1=Siemens） |
| `/Z0` ～ `/Z31` | 读写 | 控制位：写 true 发出脉冲（约 500 ms 后自动复位为 false），写 false 立即复位 |
| `/S0` ～ `/S31` | 只读状态 | 状态位反馈（随轮询推送；未订阅 Command，外部写无效） |
| `/connect` | 只读状态 | 连接状态（未订阅 Command，外部写无效） |

## 5. 行为细节

- **协议**：Modbus TCP 保持寄存器（功能码 0x03 读 / 0x06 写），TCP hex 发送；事务 ID 自增并用挂起表匹配读响应。
- **地址映射**：Beckhoff / Siemens 各有寄存器映射表（Z 控制寄存器基址、S 状态寄存器基址与数量、位→寄存器换算）；界面标签为 1 基展示，发送前经 `toProtocolAddress` 转为协议 0 基地址。
- **Z 脉冲**：置 true 写入后由延迟复位队列在 10 个 tick（约 500 ms）后自动写回复位值；复位带序号 token，期间的新脉冲会作废旧复位，避免覆盖新状态。
- **写队列**：所有写命令经 50 ms tick 队列逐条发送；同一寄存器的写命令会去重（保留最新），脉冲复位命令插在对应写命令之后；高优先级（外部/界面触发）前插。
- **S 轮询**：空闲 tick 中每 2 个 tick（约 100 ms）读一次状态寄存器（源码计数阈值为 2，与注释「1 秒」不符，以实际代码为准）；读回后逐位比对，变化才反馈并更新输出。
- **连接管理**：连接成功后立即读一次状态并启动 tick；断开时清空写队列、延迟复位与挂起读，停止 tick，Z 按钮禁用。
- **端口语义**：Z 输入以 `asBool()` 触发对应控制位；断开输入不动作。
- **连接策略**：所有端口均为 Many。
- **持久化**：`save()` 将 `host`、`port`、`serverId`、`plcType` 写入 `values.*`；`load()` 恢复后按类型重建映射与标签。
- **资源清理**：析构时断开 TCP 并停止 tick 定时器。

## 6. 使用说明与典型接法

1. 选择 PLC 类型，填写 IP 与端口，连接成功后可操作 Z。
2. 将 Z 输入设为 `true` 发出脉冲；界面按钮同理。
3. 从 S 输出读取 PLC 状态，用于联锁或显示。
4. 界面地址为 1 基展示，内部会按映射转换为协议地址。

## 7. 示例

S 5 为 `true`（门已关）→ 逻辑允许 → Z 2 写入 `true` 启动幕帘；S 接条件节点，Z 接本节点输入。
