# To Image File

## 1. 节点说明

将输入图像持续保存为图片文件。录制开启后，会按当前帧**覆盖写入**同一文件（扩展名决定格式，如 `.png` / `.jpg`）。

默认文件名：`capture.png`

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 3 | 否 | 3 | 3 | — | 末端口为 STOP（true 停止并写入文件，始终位于最后） |
| 输出 | 1 | 否 | 1 | 1 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 数据类型 | 说明 |
|------|----------|------|
| IMAGE | ImageData | 待保存的图像 |
| START | VariableData | 为 `true` 时开始录制 |
| STOP | VariableData | 为 `true` 时停止录制 |

### 输出

| 端口 | 数据类型 | 说明 |
|------|----------|------|
| RECORDING | VariableData | 当前是否正在录制（布尔） |

## 3. 界面与属性

节点控件面板（`WidgetEmbeddable=true`，**嵌入节点体**显示）：

| 控件 | 说明 |
|------|------|
| 状态文字 | **录制中**（红）或 **未录制**（灰） |
| 文件名 | 输出文件名，如 `shot.png` |
| **...** | 选择输出文件夹；悬停可查看当前目录 |
| 开始 / 停止 | 手动切换录制（与 START / STOP、`/recording` 联动） |

节点公开 3 个 `Q_PROPERTY`：

| 属性 | 类型 | 说明 |
|------|------|------|
| `file` | QString | 输出文件名（默认 `capture.png`，扩展名决定图片格式） |
| `outputDir` | QString | 输出文件夹；留空使用默认媒体库目录 `Documents/Flow/Medias/` |
| `recording` | bool | 录制状态（读写即启停） |

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/file` | 可写（命令） | 字符串，设置输出文件名 |
| `/outputDir` | 可写（命令） | 字符串，设置输出文件夹 |
| `/recording` | 可写（命令） | 布尔，开始/停止录制；状态变化反馈到该地址 |

`file`/`outputDir`/`recording` 均通过 `registerExternalBinding` 注册（绑定界面控件）并订阅 Command 事件。

## 5. 行为细节

- **端口语义**：IMAGE 仅缓存最新图像引用并重置去重时间戳；START/STOP 为 `true` 时启停录制。
- **写入调度（帧时钟驱动）**：节点就绪后连接全局 `TimestampGenerator` 帧 tick；录制中按系统帧率节流（`1000/frameRate` ms 最小间隔），且按输入时间戳去重——静止画面不重复写盘。
- **写入方式**：从输入环形缓冲读回最新帧，由 `FfmpegImageWriter` 按扩展名选格式**同步覆盖写**同一文件（GUI 线程执行，写盘耗时直接影响帧率）。
- **错误处理**：文件名为空或写盘失败 → 节点进入 Error 状态（提示"请设置输出文件名"或具体错误）并自动停止录制；写成功恢复 Valid。
- **RECORDING 输出**：启停时更新输出端口布尔值，并反馈 `/recording`。
- **持久化**：**顶层键** `file`、`outputDir`（无 `values` 包裹）；`recording` 状态不持久化，加载后默认未录制。

## 6. 使用说明与典型接法

1. 设置文件名（含扩展名）。
2. 图像源 → IMAGE。
3. 通过 START、界面按钮或 `/recording` 开始；STOP 或再次切换结束。
4. 录制期间持续用最新帧覆盖同一文件。

## 7. 示例

Camera → **To Image File**（`capture.png`）→ START 触发一次快照录制 → STOP。

# To Video File

## 1. 节点说明

将连续图像帧编码为视频文件。START 开始录制，STOP 结束并写入文件。按 wall-clock 与设定帧率采样；上游帧率低于录制 fps 时会重复写入同一帧。

默认文件名：`output.mp4`  
默认帧率：`25`

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 3 | 否 | 3 | 3 | — | 末端口为 STOP（true 停止并写入文件，始终位于最后） |
| 输出 | 1 | 否 | 1 | 1 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 数据类型 | 说明 |
|------|----------|------|
| IMAGE | ImageData | 连续视频帧 |
| START | VariableData | 为 `true` 时开始录制 |
| STOP | VariableData | 为 `true` 时停止录制并收尾写入 |

### 输出

| 端口 | 数据类型 | 说明 |
|------|----------|------|
| RECORDING | VariableData | 当前是否正在录制（布尔） |

## 3. 界面与属性

节点控件面板（`WidgetEmbeddable=true`，**嵌入节点体**显示）：

| 控件 | 说明 |
|------|------|
| 状态文字 | **录制中** / **未录制** |
| 文件名 | 如 `clip.mp4` |
| **...** | 选择输出文件夹 |
| fps | 输出帧率，默认 `25` |
| 开始 / 停止 | 手动切换录制 |

节点公开 4 个 `Q_PROPERTY`：

| 属性 | 类型 | 说明 |
|------|------|------|
| `file` | QString | 输出文件名（默认 `output.mp4`） |
| `outputDir` | QString | 输出文件夹；留空使用默认媒体库目录 |
| `fps` | double | 输出帧率（clamp 1–120；**录制中修改无效**） |
| `recording` | bool | 录制状态（读写即启停） |

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/file` | 可写（命令） | 字符串，设置输出文件名 |
| `/outputDir` | 可写（命令） | 字符串，设置输出文件夹 |
| `/fps` | 可写（命令） | 浮点，设置帧率（录制中忽略） |
| `/recording` | 可写（命令） | 布尔，开始/停止录制；状态变化反馈到该地址 |

`file`/`outputDir`/`fps`/`recording` 均通过 `registerExternalBinding` 注册（绑定界面控件）并订阅 Command 事件。

## 5. 行为细节

- **端口语义**：IMAGE 仅缓存最新图像引用；START/STOP 为 `true` 时启停录制。
- **按 wall-clock 补帧采样**：录制启动时开始计时；每个系统 tick 计算目标帧数 `elapsed×fps/1000`，不足则**用最新缓存帧重复补写**到目标数——上游帧率低于录制 fps 时输出仍保持设定帧率（重复帧），高于时不丢帧但每 tick 至多推进到当前时刻应写的帧数。
- **编码器**：`FfmpegVideoEncoder` 惰性开启——首帧到达时才按「路径+宽高+fps」打开编码器；停止时 `close()` 收尾写文件头。编码在 GUI 线程同步执行，写盘耗时会占用主线程。
- **缓存去重**：按输入时间戳刷新写缓存，同一帧不重复解码。
- **错误处理**：文件名为空、编码器打开失败或写帧失败 → 节点 Error 并自动停止录制。
- **RECORDING 输出**：启停时更新输出端口布尔值。
- **持久化**：**顶层键** `file`、`outputDir`、`fps`（无 `values` 包裹）；`recording` 不持久化。

## 6. 使用说明与典型接法

1. 设置文件名与 fps。
2. 图像源 → IMAGE。
3. START 开始录制，STOP 结束并生成文件。
4. 在 `outputDir` 或默认媒体库中查看成片。

## 7. 示例

NDI In → **To Video File**（`output.mp4`，fps=25）→ 录制约 10 秒后 STOP → 在媒体库查看。

# To Audio File

## 1. 节点说明

将一个或多个音频输入录制为音频文件。每个 `AUDIO` 端口对应输出文件的一个声道；多声道输入仅取第一声道。

默认文件名：`output.wav`

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 3 | 否 | 3 | 3 | — | 末端口为 STOP（true 停止并写入文件，始终位于最后） |
| 输出 | 1 | 否 | 1 | 1 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 数据类型 | 说明 |
|------|----------|------|
| AUDIO 0 … AUDIO N | AudioData | 可编辑的音频输入；端口索引 = 输出声道索引 |
| START | VariableData | 为 `true` 时开始录制（始终为倒数第二个输入口） |
| STOP | VariableData | 为 `true` 时停止并写入文件（始终为最后一个输入口） |

输入端口**可编辑**：在节点属性中用 **+ / -** 增减 `AUDIO` 端口；`START` / `STOP` 始终固定在末尾。录制开始时，声道数等于当前 `AUDIO` 端口数量。

### 输出

| 端口 | 数据类型 | 说明 |
|------|----------|------|
| RECORDING | VariableData | 当前是否正在录制（布尔） |

## 3. 界面与属性

节点控件面板（`WidgetEmbeddable=true`，**嵌入节点体**显示）：

| 控件 | 说明 |
|------|------|
| 状态文字 | **录制中** / **未录制** |
| 文件名 | 如 `take.wav` |
| **...** | 选择输出文件夹 |
| 开始 / 停止 | 手动切换录制 |

节点公开 3 个 `Q_PROPERTY`：

| 属性 | 类型 | 说明 |
|------|------|------|
| `file` | QString | 输出文件名（默认 `output.wav`） |
| `outputDir` | QString | 输出文件夹；留空使用默认媒体库目录 |
| `recording` | bool | 录制状态（读写即启停） |

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/file` | 可写（命令） | 字符串，设置输出文件名 |
| `/outputDir` | 可写（命令） | 字符串，设置输出文件夹 |
| `/recording` | 可写（命令） | 布尔，开始/停止录制；状态变化反馈到该地址 |

`file`/`outputDir`/`recording` 均通过 `registerExternalBinding` 注册（绑定界面控件）并订阅 Command 事件。

## 5. 行为细节

- **端口语义**：AUDIO 端口连接时要求音频源已接入共享环形缓冲（`AudioTimestampRingQueue`），否则该端口不入录制列表；断开即剔除。START/STOP 为 `true` 时启停。
- **声道映射**：录制启动时**锁定声道数 = 当前 AUDIO 端口数**；录制中增删端口不影响本次成片。端口索引 = 输出声道索引；多声道输入**只取其第一声道**；某端口无数据时该声道写 0。
- **采样调度**：录制启动后以系统帧率间隔（`1000/frameRate` ms）轮询，按时间戳从各端口环形队列取帧；各路按最短样本数对齐后交叉合并为多声道帧。
- **编码器**：`FfmpegAudioEncoder` 惰性开启（首帧到达时按「路径+采样率+声道数」打开）；停止时 `close()` 收尾。编码在 GUI 线程同步执行。
- **错误处理**：文件名为空、编码器打开失败或写帧失败 → 节点 Error 并自动停止录制。
- **RECORDING 输出**：启停时更新输出端口布尔值。
- **持久化**：**顶层键** `file`、`outputDir`（无 `values` 包裹）；`recording` 不持久化；AUDIO 端口数量随 `.flow` 的 input-count 恢复。

## 6. 使用说明与典型接法

1. 按需要增减 `AUDIO` 端口（端口 0 → 声道 0，端口 1 → 声道 1，…）。
2. 音频源接到对应端口。
3. START 开始，STOP 结束并写入文件。

## 7. 示例

Audio Decoder → **To Audio File**（双端口立体声）→ 导出 `track.wav`。

# To Text File

## 1. 节点说明

将 VariableData 以 **JSON（UTF-8）** 持续覆盖写入文本文件。录制期间，每次 `DATA` 更新都会保存当前值：单值写成 `{"default": ...}`，多键写成完整 JSON 对象（`toJsonString()`）。

默认文件名：`output.json`

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |

| 端口 | 数据类型 | 说明 |
|------|----------|------|
| DATA | VariableData | 待保存的变量数据 |
| START | VariableData | 为 `true` 时开始录制 |
| STOP | VariableData | 为 `true` 时停止录制 |

### 输出
