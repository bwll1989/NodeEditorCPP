# Delay

## 1. 节点说明

Delay 用于**按时间表延迟触发**下游逻辑。当 TRIGGER 收到一次触发后，节点会按界面中配置的「延迟时间 + 输出端口」列表，在对应时刻依次触发各个输出端口；输出数据为**最近一次触发时**从 TRIGGER 传入的载荷（透传）。

适合场景：分步执行、错峰触发、同一信号在不同时间点驱动不同分支。

## 2. 端口说明

### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | TRIGGER | VariableData | 收到触发后开始执行延迟队列；载荷会被保存并在各输出端口触发时透传 |

输入端口数量默认为 1，**可编辑**（增加输入端口不会改变延迟逻辑，非 TRIGGER 端口仅更新载荷）。

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0、1… | OUTPUT 0、OUTPUT 1… | VariableData | 在配置的延迟时刻被触发；数据内容为最近一次 TRIGGER 的输入 |

输出端口数量默认为 2，**可编辑**。端口号在延迟列表的「输出端口」列中指定。

## 3. 界面说明

- **进度条**：显示当前延迟队列的整体进度（0–100%）；空闲时显示「空闲」。
- **延迟列表**：每条规则包含**延迟时间（毫秒）**和**输出端口号**。列表会按时间排序后依次执行；同一时刻的多条规则会同时触发对应端口。
- **忽略重复信号**：勾选后，若上一轮延迟尚未结束，新的 TRIGGER 会被忽略；不勾选则新触发会**中断**当前队列并重新开始。

## 4. 使用说明

1. 在延迟列表中添加规则，例如：100 ms → 端口 0，500 ms → 端口 1。
2. 将需要触发的信号连接到 TRIGGER。
3. 将 OUTPUT 0、OUTPUT 1 等连接到需要在对应时刻执行的下游节点。
4. 触发 TRIGGER 后，节点按时间表依次 `dataUpdated` 对应输出端口。

**行为要点：**

- 未配置任何延迟规则时：触发会**立即**触发 OUTPUT 0。
- 同一时刻可配置多条规则，同时触发多个端口。
- 节点可调整大小；配置会随工程保存（`values` 字段）。

## 5. 示例

**分步灯光控制：** TRIGGER 连接「场景开始」信号；列表配置 0 ms→端口 0（开主灯）、300 ms→端口 1（开辅灯）、800 ms→端口 0（再次触发调光脚本）。勾选「忽略重复信号」可避免演出中途误触打断序列。

# Stepper

## 1. 节点说明

Stepper 是**手动步进**序列：每次 TRIGGER 按**输出端口索引**触发对应 OUTPUT（第 0 步→OUTPUT 0，第 1 步→OUTPUT 1…），然后等待下一次 TRIGGER。最后一个输出口固定为 **STEP**，输出**最近一次触发的输出端口 index**；复位后为 **-1**。超过最后一步后**自动循环**回 OUTPUT 0。

无步骤配置表；步数由可编辑的输出端口数量决定：`步数 = 输出端口数 - 1`。节点尺寸固定。

## 2. 端口说明

### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | TRIGGER | VariableData | 值为 `true` 时触发下一步 OUTPUT，步号更新；载荷透传 |
| 1 | RESET | VariableData | 值为 `true` 时 STEP/界面回到 -1（也可点界面 Reset） |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 … N-2 | OUTPUT i | VariableData | 第 i 步被 TRIGGER 时触发 |
| N-1（最后） | STEP | VariableData | 最近触发的输出端口 index；复位后为 -1 |

默认 3 个输出：OUTPUT 0、OUTPUT 1、STEP（共 2 步）。增删输出端口即可改步数。

## 3. 界面说明

上下排列：

- **步数标签**：只显示当前输出端口 index（如 `0`、`1`）；Reset 后为 `-1`。
- **Reset**：回到 -1。

**外部控制地址：**

- `/step` — 读取或设置当前端口 index（`-1` 表示复位；`≥0` 时对步数取模）
- `/reset` — 发送 `true` 时复位到 -1（与 Reset 按钮相同）

## 4. 使用说明

1. 用端口编辑调整输出数量（保留最后一口为 STEP）。
2. TRIGGER 接推进信号；各 OUTPUT 接对应动作；STEP 可接显示或下游逻辑。
3. RESET / `/reset` 将状态清为 -1；平时 TRIGGER 会自动循环。
4. 控台可用 `/step` 跳到指定输出口 index。

## 5. 示例

输出 4 口 → 3 步动作 + STEP。导控每次确认发 TRIGGER，依次打 OUTPUT 0/1/2；界面与 STEP 显示 `0`→`1`→`2`→`0`…；Reset 后显示 `-1`。
