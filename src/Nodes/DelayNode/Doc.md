# Delay

## 1. 节点说明

Delay 用于**按时间表延迟触发**下游逻辑。当 TRIGGER 收到一次触发后，节点按各输出行配置的延迟毫秒，在对应时刻触发该行对应的输出端口；输出数据为**最近一次触发时**从 TRIGGER 传入的载荷（透传）。

适合场景：分步执行、错峰触发、同一信号在不同时间点驱动不同分支。

## 2. 端口说明

### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | TRIGGER | VariableData | 收到触发后开始执行延迟队列；载荷会被保存并在各输出端口触发时透传 |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 … N-1（默认 2） | OUTPUT i | VariableData | 与 UI 第 i 行一一对应；在该行配置的延迟时刻触发 |

输出端口由左侧 **+** / 行内删除增减，不可再走 PortEdit。

## 3. 界面说明

- **左侧**：`+`、**忽略重复**、进度条（空闲 / 百分比）
- **右侧**：每行对齐一个输出端口 — 删除、延迟毫秒（`ms`）

勾选「忽略重复」时，若上一轮尚未结束，新的 TRIGGER 会被忽略；不勾选则新触发会中断当前队列并重新开始。

## 4. 使用说明

1. 用 + / 删除调整输出端口；为每行填写延迟毫秒（如 100、500）。
2. 将信号接到 TRIGGER，各 OUTPUT 接到下游。
3. 触发后按时间表依次 `dataUpdated` 对应输出端口。

**行为要点：**

- 至少保留 1 行；多行可设相同时间，同时触发多个端口。
- 配置保存在 `values`（`messages` + `ignoreRepeat`，兼容旧工程）。

## 5. 示例

**分步灯光：** 行0 = `0 ms`、行1 = `300 ms`、行2 = `800 ms`。TRIGGER 接场景开始；OUTPUT 接开灯/调光。勾选「忽略重复」避免中途误触打断。

# Stepper

## 1. 节点说明

Stepper 是**手动步进**序列：每次 TRIGGER 按**输出端口索引**触发对应 OUTPUT（第 0 步→OUTPUT 0，第 1 步→OUTPUT 1…），然后等待下一次 TRIGGER。最后一个输出口固定为 **STEP**，输出**最近一次触发的输出端口 index**；复位后为 **-1**。超过最后一步后**自动循环**回 OUTPUT 0。

无步骤配置表；步数由可编辑的输出端口数量决定：`步数 = 输出端口数 - 1`。节点尺寸固定。

## 2. 端口说明

### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | TRIGGER | VariableData | 值为 `true` 时触发下一步 OUTPUT，步号更新；载荷透传 |
| 1 | RESET | VariableData | 值为 `true` 时 STEP/界面回到 -1（也可点界面 Reset） |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 … N-2 | OUTPUT i | VariableData | 第 i 步被 TRIGGER 时触发 |
| N-1（最后） | STEP | VariableData | 最近触发的输出端口 index；复位后为 -1 |

默认 3 个输出：OUTPUT 0、OUTPUT 1、STEP（共 2 步）。增删输出端口即可改步数。

## 3. 界面说明

上下排列：

- **步数标签**：只显示当前输出端口 index（如 `0`、`1`）；Reset 后为 `-1`。
- **Reset**：回到 -1。

**外部控制地址：**

- `/step` — 读取或设置当前端口 index（`-1` 表示复位；`≥0` 时对步数取模）
- `/reset` — 发送 `true` 时复位到 -1（与 Reset 按钮相同）

## 4. 使用说明

1. 用端口编辑调整输出数量（保留最后一口为 STEP）。
2. TRIGGER 接推进信号；各 OUTPUT 接对应动作；STEP 可接显示或下游逻辑。
3. RESET / `/reset` 将状态清为 -1；平时 TRIGGER 会自动循环。
4. 控台可用 `/step` 跳到指定输出口 index。

## 5. 示例

输出 4 口 → 3 步动作 + STEP。导控每次确认发 TRIGGER，依次打 OUTPUT 0/1/2；界面与 STEP 显示 `0`→`1`→`2`→`0`…；Reset 后显示 `-1`。
