# Math Add
**Math Operation 节点**

## 1. 节点说明

Math Operation 插件提供一组算术节点，对数值型 VariableData 做运算，结果从单一输出端口输出。无内嵌界面。不同变体按运算语义配置**输入端口数量**与**端口是否可编辑**。

| 变体名称 | 运算 | 输入端口 | 端口可编辑 |
|----------|------|----------|------------|
| Math Add | 多路求和 | 默认 2，可增删 | 是 |
| Math Sub | 减法 | 2 | 否 |
| Math Mul | 多路连乘 | 默认 2，可增删 | 是 |
| Math Div | 除法（除数为 0 时结果为 0） | 2 | 否 |
| Math Mod | 浮点取模（`fmod`） | 2 | 否 |
| Math Pow | 幂运算（`pow`） | 2 | 否 |
| Math Max | 多路取较大值 | 默认 2，可增删 | 是 |
| Math Min | 多路取较小值 | 默认 2，可增删 | 是 |
| Math Abs | 绝对值 | 1 | 否 |
| Math Floor | 向下取整 | 1 | 否 |
| Math Ceil | 向上取整 | 1 | 否 |
| Math Round | 四舍五入 | 1 | 否 |
| Math Sqrt | 平方根（负数时输出 0） | 1 | 否 |
| Math Log | 自然对数（非正数时输出 0） | 1 | 否 |
| Math Avg | 多路平均值 | 默认 2，可增删 | 是 |
| Math Hypot | 斜边长度 `hypot(x, y)` | 2 | 否 |

输入会按 `toDouble()` 转为浮点数参与计算；任一输入更新或断开连接后输出立即刷新。可编辑端口的节点可在属性面板的「端口编辑」页增删输入端口。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 2 | 是 | 1 | 不限 | VariableData | 无 |
| 输出 | 1 | 否 | 1 | 1 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0…n | INPUT / INPUT n | VariableData | 操作数；一元运算仅 1 个端口，二元固定 2 个，可编辑变体默认 2 个并可扩展 |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | OUTPUT 0 | VariableData | 运算结果（数值） |

## 3. 界面与属性

各变体无内嵌面板，无额外控件。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

本节点未注册任何专属 OSC 地址（源码无 `Q_PROPERTY` 外部属性、无 `registerExternalBinding` 调用），不能通过 OSC/网页等方式远程控制；无可调参数，运算完全由输入端口驱动。

## 5. 行为细节

- **重算时机**：任一输入写入或断开连接后立即重算并推送（无 tick、无线程参与，纯同步计算）。
- **可变参聚合**：对**已连接**端口逐个累加；全部断开时输出 0；可编辑端口（属性面板「端口编辑」页）增删后立即按新端口数参与计算。
- **连接策略**：输入/输出端口均为 Many（可一对多）。
- **持久化**：无参数可保存（save/load 为空实现，输入状态不持久化）。

## 6. 使用说明与典型接法

1. 在节点库中选择所需变体（如 Math Mul）。
2. 将两路数值数据接到 INPUT 0、INPUT 1。
3. 将 OUTPUT 0 接到后续节点（如 Extract、Merge、显示等）。

除法节点在除数为 0 时输出 0，避免异常中断流程。

## 7. 示例

**亮度缩放：** Math Mul 将 0–1 的系数（INPUT 1）与 DMX 通道值（INPUT 0）相乘，输出接 Artnet 或下游控制。  
**周期性数值：** Math Mod 对递增计数取模，实现循环索引。

# Math Sub

## 1. 节点说明

Math Operation 插件的一员：对数值型 VariableData 做算术运算，结果从单一输出端口 OUTPUT 0（VariableData，数值）输出。输入按 `toDouble()` 转为浮点数参与计算；任一输入更新或断开连接后输出立即刷新。

需要差值（行程差、差分比较）时用本节点；需要多路累加时用 Math Add。

**运算**：OUT = A − B（INPUT 0 减 INPUT 1）。

除数为 0 的保护只存在于 Math Div；本节点无特殊边界。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 2 | 否 | 2 | 2 | — | 无 |
| 输出 | 1 | 否 | 1 | 1 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | INPUT 0（A） | VariableData | 被减数；按 `toDouble()` 转浮点；**断开时：按 0 参与**；收到非数值数据时按 0 处理 |
| 1 | INPUT 1（B） | VariableData | 减数；同上 |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | OUTPUT 0 | VariableData | A − B 的差值；B 大于 A 时为负数 |

## 3. 界面与属性

本节点无可配置属性，无内嵌界面控件。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

本节点未注册任何专属 OSC 地址（源码无 `Q_PROPERTY` 外部属性、无 `registerExternalBinding` 调用），不能通过 OSC/网页等方式远程控制；无可调参数，运算完全由输入端口驱动。

## 5. 行为细节

- **重算时机**：任一输入写入或断开连接后立即重算并推送（无 tick、无线程参与，纯同步计算）。
- **缺失输入**：INPUT 0/1 任一断开时按 0 参与（A−0=A、0−B=−B）。
- **连接策略**：输入/输出端口均为 Many（可一对多）。
- **持久化**：无参数可保存（save/load 为空实现，输入状态不持久化）。

## 6. 使用说明与典型接法

1. INPUT 0 接基准值（如目标位置），INPUT 1 接当前值。
2. OUTPUT 0 接 Logic 节点或显示节点做差值监控。

## 7. 示例

**行程差监控：** Nav Controller 的目标坐标与 PosiStageNet 实时坐标分别接 INPUT 0/1，输出接 Extract 取绝对值后做安全阈值判断。

# Math Mod

## 1. 节点说明

Math Operation 插件的一员：对数值型 VariableData 做算术运算，结果从单一输出端口 OUTPUT 0（VariableData，数值）输出。输入按 `toDouble()` 转为浮点数参与计算；任一输入更新或断开连接后输出立即刷新。

需要循环索引（跑马灯、帧序号循环）时用本节点。

**运算**：OUT = fmod(A, B)（C 风格浮点取模，结果符号跟随 A）；**B 为 0 时输出 NaN**（显示为 null/0）。

与整数取模不同，fmod 对小数同样适用；需要整数语义时在前面接 Math Floor。

> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | INPUT 0（A） | VariableData | 被取模值；断开时按 0 参与 |
| 1 | INPUT 1（B） | VariableData | 模值；**为 0 时结果为 NaN**，建议保证 B 恒为正 |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | OUTPUT 0 | VariableData | fmod(A, B)；结果符号与 A 相同 |

## 5. 行为细节

- **重算时机**：任一输入写入或断开连接后立即重算并推送（无 tick、无线程参与，纯同步计算）。
- **fmod 语义**：C 风格浮点取模，结果符号跟随 A；**B 为 0 时结果为 NaN**（fmod 标准行为，无除零保护）。

## 6. 使用说明与典型接法

1. INPUT 0 接递增计数（如 Count 节点输出），INPUT 1 接周期长度。
2. 输出即为循环索引。

## 7. 示例

**循环切换：** Count 递增值对 3 取模，输出接 Switch 的 INDEX，实现 0→1→2→0 循环切换三路信号。

# Math Avg

## 1. 节点说明

Math Operation 插件的一员：对数值型 VariableData 做算术运算，结果从单一输出端口 OUTPUT 0（VariableData，数值）输出。输入按 `toDouble()` 转为浮点数参与计算；任一输入更新或断开连接后输出立即刷新。

需要多路平均（平滑、去噪、均值）时用本节点。

**运算**：OUT = 所有已连接输入之和 ÷ 已连接端口数。

端口可编辑：可在属性面板「端口编辑」页增删输入端口。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 2 | 是 | 1 | 不限 | VariableData | 无 |
| 输出 | 1 | 否 | 1 | 1 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0…n | INPUT 0、INPUT 1 … | VariableData | 参与平均的数值；默认 2 个，可增删；**断开的端口不参与平均**（分母只数已连接端口）；全部断开时输出 0 |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | OUTPUT 0 | VariableData | 已连接输入的平均值 |

## 3. 界面与属性

无内嵌面板。可在属性面板「端口编辑」页增删输入端口。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

本节点未注册任何专属 OSC 地址（源码无 `Q_PROPERTY` 外部属性、无 `registerExternalBinding` 调用），不能通过 OSC/网页等方式远程控制；无可调参数，运算完全由输入端口驱动。

## 5. 行为细节

- **重算时机**：任一输入写入或断开连接后立即重算并推送（无 tick、无线程参与，纯同步计算）。
- **可变参聚合**：对**已连接**端口求和后除以**已连接端口数**（断开端口既不参与分子也不参与分母）；全部断开时输出 0。
- **连接策略**：输入/输出端口均为 Many（可一对多）。
- **持久化**：无参数可保存（save/load 为空实现，输入状态不持久化）。

## 6. 使用说明与典型接法

1. 多路同类信号接 INPUT。
2. OUTPUT 0 输出平均值。

## 7. 示例

**多传感器平滑：** 多个温度传感值接 Math Avg，输出做展示或回控。

# Math Hypot

## 1. 节点说明

Math Operation 插件的一员：对数值型 VariableData 做算术运算，结果从单一输出端口 OUTPUT 0（VariableData，数值）输出。输入按 `toDouble()` 转为浮点数参与计算；任一输入更新或断开连接后输出立即刷新。

需要直角三角形斜边（√(x²+y²)，二维距离）时用本节点。

**运算**：OUT = hypot(A, B) = √(A² + B²)。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 2 | 否 | 2 | 2 | — | 无 |
| 输出 | 1 | 否 | 1 | 1 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | INPUT 0（A） | VariableData | 直角边 1；断开时按 0 参与 |
| 1 | INPUT 1（B） | VariableData | 直角边 2；同上 |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | OUTPUT 0 | VariableData | 斜边长度（恒非负） |

## 3. 界面与属性

本节点无可配置属性，无内嵌界面控件。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

本节点未注册任何专属 OSC 地址（源码无 `Q_PROPERTY` 外部属性、无 `registerExternalBinding` 调用），不能通过 OSC/网页等方式远程控制；无可调参数，运算完全由输入端口驱动。

## 5. 行为细节

- **重算时机**：任一输入写入或断开连接后立即重算并推送（无 tick、无线程参与，纯同步计算）。
- **hypot 语义**：`std::hypot` 计算斜边，内部避免中间量溢出（大数值下比手写 √(A²+B²) 更稳）；结果恒非负。
- **缺失输入**：A/B 任一断开时按 0 参与。
- **连接策略**：输入/输出端口均为 Many（可一对多）。
- **持久化**：无参数可保存（save/load 为空实现，输入状态不持久化）。

## 6. 使用说明与典型接法

1. Δx 接 INPUT 0，Δy 接 INPUT 1。
2. OUTPUT 0 输出平面距离。

## 7. 示例

**跟踪距离：** 目标坐标差值接 Math Hypot，输出距离值接 Logic 做进入/离开区域判断。
