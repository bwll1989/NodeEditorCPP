# ROI 节点

## 1. 节点说明

ROI 节点用于在输入图像上选择感兴趣区域，并输出对应的裁剪图像与 ROI 矩形。

节点内部以**归一化矩形**作为单一真相保存 ROI，因此当输入图像分辨率变化时，ROI 会尽量保持相同的相对区域，而不是固定死像素坐标。

## 2. 端口说明

### 输入

- **IMAGE**（ImageData）：输入图像。
- **RECT**（VariableData）：外部输入 ROI 矩形。

`RECT` 输入支持两种格式：

- `QRectF` 归一化矩形：`x/y/width/height` 范围在 `[0, 1]` 内。
- `QRectF` 或 `QRect` 像素矩形：以输入图像像素坐标表示。

当图像尚未接入时，`RECT` 输入会暂存；待图像到达后再应用到当前输入图像。

### 输出

- **IMAGE**（ImageData）：当前 ROI 裁剪结果。
- **RECT**（VariableData）：当前 ROI 的像素矩形 `QRect`。

## 3. ROI 行为说明

- 节点内部始终保存归一化 ROI。
- 鼠标拖拽、属性修改、外部 `RECT` 输入，最终都会转换为归一化矩形后保存。
- 输出 `RECT` 始终为当前输入图像分辨率下换算得到的**像素矩形**。
- 当输入图像分辨率变化时，节点会根据归一化 ROI 自动重新计算像素矩形和裁剪结果。
- ROI 超出图像范围时会自动裁剪到合法区域。
- ROI 无效、输入图像为空、或裁剪区域为空时，`IMAGE` 输出为空图像。

## 4. 界面说明

- 内嵌预览区会显示输入图像。
- 在预览区按住鼠标左键拖拽，可绘制或修改 ROI 方框。
- 面板会同步显示当前 ROI 的像素坐标与图像尺寸信息。
- 当通过外部 `RECT` 端口输入 ROI 时，界面中的方框也会同步更新。

## 5. 使用说明

### 方式一：手动框选

1. 将图像接到 **IMAGE** 输入。
2. 在节点预览区用鼠标左键拖出方框。
3. 将输出 **IMAGE** 接到后续处理节点。
4. 如需将 ROI 坐标传给其他节点，可使用 **RECT** 输出。

### 方式二：外部控制 ROI

1. 将图像接到 **IMAGE** 输入。
2. 将一个 `QRectF` 或 `QRect` 变量接到 **RECT** 输入。
3. 节点会自动更新预览框，并输出对应裁剪结果。

## 6. 示例

- 摄像头画面 → ROI → Object Detection，只检测指定区域。
- 视频流 → ROI → Image Compare，只比较局部区域。
- 图像源 → 外部 `RECT` 控制 → ROI，实现程序化裁剪。
