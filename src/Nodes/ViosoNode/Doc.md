# Vioso

## 1. 节点说明

使用 [VIOSO WarpBlend API](https://github.com/vioso/VIOSO_API) 加载 `.vwf`，对输入图像做 Warp + Blend。按文件内通道数自动展开多路输出（单机即为 1 路）。

依赖：`3rdParty/VIOSO_API`（构建时拷贝 `VIOSOWarpBlend64.dll` 到 `bin/`）。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 1 | 否 | 1 | 1 | — | 无 |
| 输出 | 1 | 否 | 1 | 64（随 .vwf 通道数） | IMAGE | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。
>
> 输出口数不能手动增删：初始为 1，选定 `.vwf`（或 Reload）后按文件通道数自动增删，钳制在 1–64。



### 输入

- **IMAGE**：待变形源图像。

### 输出

- **IMAGE** / **IMAGE 0…N-1**：N = `.vwf` 通道数（上限 64）；每路对应一个投影机。

## 3. 界面与属性

内嵌控件面板（`WidgetEmbeddable=true`，可嵌入节点体显示，也可收入右侧属性面板）：

| 控件 | 说明 |
|------|------|
| 文件选择 | 媒体库 Vioso 分类中的 `.vwf` |
| Passkey | 加密 `.vwf` 的 AES-128 密钥：32 位十六进制，或 16 字节明文；空=不加密 |
| Reload | 重新加载校准并按文件重算输出口数 |

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/configFile` | 读写 | `.vwf` 路径（媒体库相对路径或绝对路径）；写入后立即重新加载并按通道数重算输出口。 |
| `/passkey` | 读写 | AES-128 密钥字符串；写入后节点重新初始化（下一帧生效）。 |
| `/reload` | 写 | 写 `true` 触发重载（同步输入框中未提交的 Passkey、重建 warper、重算端口）；写 `false` 无效果。触发后属性短暂置 true 再回 false，会推送两次反馈。 |

3 个地址均注册了带属性 member 的绑定：模型就绪时各推送一次初始值，此后属性每次变化（界面或外部写入）自动推送反馈。

## 5. 行为细节

```
IMAGE → 输入翻 V → 各通道 VWB_render → 输出翻 V → IMAGE[i]
```

- 显示管线的 V 翻转在 `runGl` 外侧（输入、输出各翻一次），和变形计算本身无关；不传 `VWB_STATEMASK_VIEWPORT`。
- 帧驱动：挂在全局帧计数上，每帧排队触发一次处理；同一帧且参数、文件均未变时跳过 GPU。
- 输入帧查找：按目标时间戳在共享环形队列回溯最多 64 帧找 GPU 纹理，找不到回落最新一帧；输出时间戳为当前系统帧计数。
- 每路输出对应独立 warper 实例；通道数变化时 warper 槽位随之增删。
- 失败锁定：Init/渲染失败后置错误状态并停止每帧重试（避免 VIOSO 内部泄漏导致内存暴涨），直到换文件或点 Reload 才解锁；`VWB_Init` 报错时追加 Passkey 缺失提示。
- Passkey 解析失败（既不是 32 位 hex 也不是 16 字节）直接报错并清空输出。
- 无输入、输入断开或未选文件时清空全部输出队列。
- Reload 会先同步输入框里尚未提交的 Passkey 内容，再重建 warper 并重算端口。
- 持久化：`values` 子对象 2 键（configFile / passkey）；加载后强制重新初始化并按文件重算端口（加载阶段不广播端口变化）。

## 6. 使用说明与典型接法

![{438AC022-B4D2-4676-9202-E6692C88DB92}.png](%7B438AC022-B4D2-4676-9202-E6692C88DB92%7D.png)
1. 导入 `.vwf` 到媒体库（Vioso 分类），节点上选择。
2. 若 VIOSO 日志报 `Passkey missing`，向 VIOSO 索取 16 字节密钥并填入 Passkey（常用 32 位 hex），再点 Reload。
3. IMAGE 接源；各输出口分别接 Display / Spout 等。
4. 校准更新后点 Reload。
