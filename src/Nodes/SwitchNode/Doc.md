# Switch

## 1. 节点说明

Switch 根据**索引**从多路输入中选择一路，转发到单一输出。类似多路开关：INDEX 决定当前选中的是 INPUT 0、INPUT 1 还是其它数据端口（最后一个输入端口固定为 INDEX）。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 3 | 是 | 1 | 不限 | VariableData | 末端口为 INDEX（选择索引，类型同为 VariableData 但语义不同，始终位于最后） |
| 输出 | 1 | 否 | 1 | 1 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 … N-2 | INPUT 0、INPUT 1 … | VariableData | 候选数据源 |
| 最后一个 | INDEX | VariableData | 整型索引，选择输出 `INPUT[index]` 的数据 |

默认共 3 个输入（INPUT 0、INPUT 1、INDEX）；**可编辑**以增加更多 INPUT，INDEX 始终为最后一个端口。

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | OUTPUT 0 | VariableData | 当前 INDEX 选中的那路输入数据 |

## 3. 界面与属性

本节点不提供自定义控件；`WidgetEmbeddable=false`，框架基于 Q_PROPERTY 自动生成的属性树显示在右侧属性面板，不嵌入节点体，仅含一个 Index 数字框（与属性双向同步）。

节点公开 1 个 `Q_PROPERTY`：

| 属性 | 类型 | 说明 |
|------|------|------|
| `index` | int | 当前选中的输入索引（默认 0） |

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/index` | 可写（命令） | 整型，切换选中的输入通道；与 INDEX 端口、属性面板等效 |

`index` 通过 `registerExternalBinding` 注册并订阅 Command 事件，外部写入实时生效。

## 5. 行为细节

- **端口语义**：数据到达最后一个端口（INDEX）时按整型设置索引；到达其他端口时缓存该路数据并触发输出刷新。
- **输出取值**：输出恒为 `INPUT[index]` 的缓存值；INDEX、任一路 INPUT 或 `/index` 任一变化都会触发输出更新。
- **断开不清缓存**：某路 INPUT 断开后，其旧数据仍留在缓存中，索引指向它时输出保持旧值（与按行清缓存的 Merge 类节点不同）。
- **索引不校验范围**：`index` 不做 clamp/越界检查，指向未连接或未收到数据的通道时输出为空值。
- **索引去重**：`setIndex` 对相同值跳过，不触发多余刷新。
- **持久化**：`values.val`（整型索引）；加载后恢复索引。

## 6. 使用说明与典型接法

1. 将多路备选数据接到 INPUT 0、INPUT 1…
2. 将索引源（数值或来自逻辑节点）接到 INDEX。
3. 从 OUTPUT 0 取当前选中通道的数据。
4. INDEX 或任一路 INPUT 变化时，输出会更新。

## 7. 示例

**三路视频源切换：** INPUT 0/1/2 接三个源，INDEX 接控台页码或 Logic 比较结果；输出接显示链路。  
**远程切路：** 将 `/index` 绑定 OSC，控台发送 0/1/2 即可切换。
