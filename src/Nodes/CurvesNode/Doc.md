# Curve1D

## 1. 节点说明

Curve1D 提供**一维值曲线（包络/自动化曲线）**采样与周期播放能力：曲线就是函数 **y = f(progress)**——X 轴即进度（0~1），Y 轴即输出值。支持 1~16 条曲线，每条曲线独占一个输出端口，输出该曲线在当前进度处的 **Y 单值**（double）。适合标量包络、亮度/音量渐变、单参数动画等场景。

**插值采用单调三次样条（Fritsch–Carlson）**——曲线在关键点之间严格单调、不过冲、不回弯（DAW 自动化曲线的标准算法），编辑器绘制与节点输出严格一致；进度在首末点范围之外时保持端点值（hold 平段）。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 3 | 否 | 3 | 3 | SyncData（SYNC） | 无 |
| 输出 | 3（SYNC + PROGRESS + 1 曲线） | 否（曲线端口随曲线增删自动变化） | 3 | 18 | VariableData（曲线） | 无 |

> 输出端口 0 = **SYNC 时钟源**、端口 1 = **PROGRESS 回放进度**（0~1，实时更新）；曲线端口从 2 开始（端口 2..N+1 对应曲线 1..N），编辑弹窗中「+曲线 / -曲线」时曲线端口在末尾动态增减——增删只发生在末尾，前两个端口连线位置恒稳定。

### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | START | VariableData | 收到真值（非 0/true）时启动周期播放 |
| 1 | STOP | VariableData | 收到真值时停止播放（进度定格） |
| 2 | SYNC | SyncData | 同步源共享句柄；连接后播放头由同步源接管（播放态联动 + 位置按周期映射） |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | SYNC | SyncData | **时钟源输出**：持续发布当前播放头（秒位置 + 锚点帧 + 播放态），下游节点的 SYNC 输入接入后跟随本节点播放头（可级联同步多条曲线节点） |
| 1 | PROGRESS | VariableData | **回放进度**（double，0~1）：播放推进 / 面板拖拽 / SYNC 跟随 / OSC 定位均实时更新 |
| i（2..N+1） | 曲线 i−1 | VariableData | 第 i−1 条曲线在当前进度处的 Y 值（double） |

## 3. 界面与属性

节点体内嵌紧凑面板：大号时间读数 + **进度条**（可拖拽定位播放头）+ 启动/循环（**默认单次播放**）+ 编辑曲线按钮（双击节点为库默认展开/折叠，不弹窗）。

「编辑曲线」打开独立弹窗（非模态，760×500）——**函数图/包络编辑器**（对齐 DAW 自动化编辑器形态）：

- **工具行**：启动/停止（与节点面板联动）/ +曲线 / -曲线 / 添加点 / 删除点 / 适应视图 / 周期（拖拽数值框，0.1~3600 s，默认 5 s）/ 采样率（拖拽数值框，1~100 Hz，默认 30）；工具行下方另有**进度条**（与节点面板进度条联动，0~1，拖拽实时定位播放头）。
- **函数图视口（主体）**：X 轴显示**完整周期的时间刻度（秒）**——刻度值 = 进度 × 周期，工具行修改周期后自动刷新（如周期 5s 则横轴 0~5.00s）；Y 轴为输出值（1-2-5 自适应刻度 + 细网格 + 轴标签）；**左上角图例**每条曲线一条色带 + 名称 + 实时输出值，点击行切换编辑目标；每条曲线独立配色（红/绿/蓝/橙…），选中曲线 3px 加粗并显示控制点，其余曲线细线同窗显示；绿色竖直播放头 + 各曲线在播放头处的值圆点。
- **交互**：左键拖动控制点（横轴=周期内时间，Y 自由，X 不越过相邻点）、单击曲线或图例切换选中、双击按时间位置插入点、中键或右键上下平移（仅 Y）、滚轮缩放（仅 Y，以鼠标为锚点——X 轴恒显示完整周期，无横向缩放）、Delete 删除选中点、「适应视图」= Y 轴适配全部曲线值范围。
- **点编辑行**（视口上方，紧凑单行）：选中点的 **时间（秒，0~周期，内部按 进度=时间/周期 存储）/ 数值**。

公开属性：`period`（秒）、`loop`（默认 false 单次）、`play`、`sampleRate`（1~100 默认 30）、`curveCount`、`activeCurve`。（`progress` 为内部状态：不进入右键外部控制菜单，OSC `/progress` 仅可写入定位；实时进度输出走 PROGRESS 端口。）

## 4. 播放引擎与同步

- 与 Curve3D/Curve2D 完全一致：本地播放按 `1/(周期×采样率)` 采样网格量化推进（一个周期恰好 = 周期 × 采样率次输出）；窗口拖拽、弹窗开关等动作短暂阻塞界面后，引擎会自动补齐缺失的输出点，输出序列完整不丢点；SYNC 从机模式：只做播放态联动（源起播则起播、源停止则停止），**位置跟随由本机按采样网格执行（与主机格点对齐），从机输出点数与主机一致**（源跳变过大时直接重对齐不扫掠）；OSC `/progress` 可直接设定位置。**停止（手动/播完/OSC/SYNC 联动）时进度自动归零**，再次启动从头播放。
- 所有曲线共享同一 progress，任一时刻各端口输出同一进度下各自曲线的 Y 值。

## 5. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/period` | 读/写 | 周期时长（秒，0.1~3600） |
| `/loop` | 读/写 | 是否循环 |
| `/play` | 读/写 | 播放态（true 启动 / false 停止） |
| `/stop` | 只写 | 停止播放 |
| `/sampleRate` | 读/写 | 采样率（Hz，1~100） |

## 6. 行为细节

- **采样语义**：输出 = 单调三次插值（Fritsch–Carlson）在 X=progress 处的 Y 值——关键点之间严格单调、不过冲不回弯；进度小于首点 X 或大于末点 X 时保持端点值（hold，编辑器同步绘制平段，所见即输出）。控制点按 X 升序约束（拖动/数值编辑自动钳制）。
- progress 变化立即推送全部输出端口；任一曲线编辑也会立即重新推送（拖动控制点即可实时听到/看到输出变化）。
- 曲线与播放参数（进度/周期/循环/采样率）随场景自动保存与加载；兼容旧版单曲线存档。
- 新建曲线默认形状为 0→1 线性斜坡；「添加点」在最大 X 间隙的中点插入关键点（值取曲线该处的当前输出）。

## 7. 使用说明与典型接法

1. 「编辑曲线」打开函数图弹窗：点击图例或曲线切换编辑目标，「+曲线」新增一条包络；设定周期与循环。
2. START/STOP 接 Trigger/比较节点做外部启停；SYNC 接时间线/解码器同步播放头。
3. 将「曲线 N」端口的单值输出接到标量参数（亮度/音量/位置分量等）；多条曲线一次启动同步输出，图例中可直接读取各曲线实时值。

# Curve3D

## 1. 节点说明

Curve3D 提供**多曲线三维采样**与**周期运动**能力：支持任意条（1~16）三维曲线，每条曲线在独立端口上输出自己的采样点（`[x, y, z]` 列表）。所有曲线共享同一播放引擎（进度 / 周期 / 采样率 / 循环），同步推进。曲线为向心 Catmull-Rom 样条，按弧长均匀取样。

典型用途：多灯具/多机械臂/多摄像机的空间运动路径编排、三维映射位置驱动、随时间周期变化的空间参数组。

编辑视口支持右键旋转、中键平移、滚轮缩放、拖动控制点、按住 Shift 轴向约束、双击/右键加点和视角球。

|------|----------|--------|------|------|--------------|------------|
| 输入 | 3 | 否 | 3 | 3 | SyncData（SYNC） | 无 |
| 输出 | 3（SYNC + PROGRESS + 1 曲线） | 否（曲线端口随曲线增删自动变化） | 3 | 18 | VariableData（曲线） | 无 |

| 1 | PROGRESS | VariableData | **回放进度**（double，0~1）：播放推进 / 面板拖拽 / SYNC 跟随 / OSC 定位均实时更新 |

> 每条曲线独占一个端口；端口 2 = 曲线 1，端口 3 = 曲线 2，以此类推（端口 0 是 SYNC 时钟源、端口 1 是 PROGRESS 回放进度）。删除曲线时，其对应端口上的连线会被节点图自动移除。

## 3. 界面与属性

节点体内嵌紧凑控制面板：

- **双击节点**：展开/折叠面板（库默认行为，与其他节点一致）。

- **时间读数**：大号 `hh:mm:ss:zzz` 显示，指示当前周期内已播时间（progress × 周期）。
- **进度条**：可拖拽定位播放头（0~1），随播放实时推进；与弹窗进度条联动。
- **启动/停止**：checkable 按钮，启动后按周期推进；停止后进度自动归零。
- **循环**：**默认不勾选（单次播放）**；勾选后播放头到达周期末尾自动回绕（fmod），不勾选则推进到末尾后自动停止。
- **编辑曲线**：点击打开「三维曲线编辑器」独立弹窗进行编辑（曲线列表、周期、采样率、启动/停止都在弹窗中）。

弹窗编辑器（非模态，860×560，可与播放/外部控制同时使用）分为四个区域：

- **工具行**：启动/停止（与节点面板按钮联动）/ +曲线（输出端口 +1，新曲线以当前曲线末点附近为起点）/ -曲线（至少保留一条，端口连线自动移除）/ 闭合（作用于选中曲线）/ 添加点 / 删除点 / 适应视图 / 周期（拖拽数值框，一个完整周期的时长，秒，0.1 ~ 3600，默认 5 s）/ 采样率（拖拽数值框，播放时每秒输出更新次数，1 ~ 100 Hz，默认 30）；工具行下方另有**进度条**（与节点面板进度条联动，0~1，拖拽实时定位播放头）。
- **图例（视口左上角内嵌）**：每条曲线一行色带 + 名称（`曲线 1`、`曲线 2`…），**点击行切换编辑目标**（替代旧版左侧曲线列表）。
- **三维视口（主体）**：**同窗显示全部曲线**——选中的曲线高亮渲染（进度染色 + 控制点 + 播放头，可编辑），其余曲线以各自调色板暗色幽灵线叠加（**与图例色带一一对应**）。**单击曲线或图例行即切换编辑目标**（保持相机视角）；**双击曲线某位置自动在该处插入控制点**（双击其它曲线先切换选中）；双击地面加点、右键菜单加。「适应视图」的包围盒涵盖所有曲线。交互：右键旋转、中键平移、滚轮缩放、左键拖动选中曲线的控制点（按住 X/Y/Z 键轴向约束）、视角球切换正交视图。
- **点编辑行**（视口上方，紧凑单行）：当前选中曲线的选中点 X / Y / Z 数值（可拖动调节）。

公开属性：`closed`（bool，当前选中曲线的闭合状态）、`period`（double，周期秒）、`loop`（bool，循环，默认 false 单次）、`play`（bool，播放态）、`sampleRate`（int，采样率 Hz，1~100 默认 30）、`curveCount`（int，曲线数）、`activeCurve`（int，当前选中曲线索引）。（`progress` 为内部状态：不进入右键外部控制菜单；OSC `/progress` 仅可写入定位，实时进度输出走 PROGRESS 端口。）

## 4. 播放引擎与同步

- 所有曲线共享同一个 `progress`（0~1）与播放引擎，任一时刻各端口输出的是同一条"播放头"位置下各自曲线的采样点。
- **本地播放**：tick 间隔由采样率决定；循环模式 fmod 回绕，非循环到达 1 后自动停止并复位按钮。**停止（手动/播完/OSC/SYNC 联动）时进度自动归零**，再次启动从头播放。
- **SYNC 跟随**（从机模式）：
  - 播放态联动：源起播则自动起播，源停止则自动停止；非循环且源位置已超出一个周期时不起播（定格待命，源回拉后恢复跟随）。
  - 位置跟随：`progress = 源期望位置 / 周期`，循环 fmod 回绕，非循环钳制 0~1；**输出由本机按采样网格量化推进（从上一已输出格点逐格补推 + 追帧补点），一个周期输出点数 = 周期 × 采样率，与本地播放/主机一致**。源位置跳变（主机拖进度条 / OSC）幅度过大时，判定为跳变——直接重对齐，不做整段扫掠补推。
  - 播放头位置由同步源接管；断开 SYNC 后交还本地时钟。
- 手动/外部驱动：OSC `/progress` 可随时直接设定位置（与播放引擎并存）。

## 5. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/closed` | 读/写 | 当前选中曲线是否闭合（布尔） |
| `/period` | 读/写 | 周期时长（秒，0.1~3600） |
| `/loop` | 读/写 | 是否循环（布尔） |
| `/play` | 读/写 | 播放态（布尔，true 启动 / false 停止） |
| `/stop` | 只写 | 停止播放（等价 `/play` false） |
| `/sampleRate` | 读/写 | 采样率（Hz，1~100） |

## 6. 行为细节

- 采样语义：`progress` 为**弧长比例**——0 为各曲线自己的起点，1 为终点，中间按弧长均匀；多条曲线长度不同时，各自独立做弧长归一化。
- progress 变化（播放推进 / SYNC 跟随 / OSC / 面板）都会立即重新采样并推送**全部**输出端口；任一曲线编辑（改点/加删点/闭合）也会立即重新推送。
- 播放推进节奏由**采样率**决定：进度按 `1/(周期×采样率)` 的采样网格量化推进，**一个周期的输出更新次数恰好 = 周期 × 采样率**（如 5s × 30Hz = 150 次），与定时器抖动无关；窗口拖拽、弹窗开关等动作短暂阻塞界面后，引擎会自动补齐缺失的输出点（追帧补点，限幅一个周期），输出点序列保持完整不丢点；采样率范围 1~100 Hz（默认 30）。
- **默认单次播放**：启动后推进到周期末尾自动停止；勾选「循环」后到达末尾 fmod 回绕继续。
- 曲线形状、闭合状态与播放参数（进度/周期/循环/采样率）随场景自动保存与加载；兼容旧版单曲线存档。

## 7. 使用说明与典型接法

1. 选中节点，点击面板「编辑曲线」打开弹窗；工具行「+曲线」新增曲线，视口左上角图例（或直接单击曲线）切换编辑目标后编辑其控制点。
2. 设定「周期」与「循环」（所有曲线共用）；需要某条曲线首尾相连时选中它并勾选「闭合」。
3. 点击「启动」（或 OSC `/play` true）开始按周期运动；时间读数随播放推进，所有曲线同步。
4. 需要外部启停控制时，用 Trigger/比较节点等输出真值到 START / STOP 端口。
5. 需要与时间线/解码器同步时，将时间线节点或解码器的 SYNC 输出连接到 SYNC 端口，播放头自动跟随同步源。
6. 将各曲线的输出端口分别接到对应的下游节点（如 OSC 输出、自定义脚本、灯具位置参数）。

## 8. 示例

**多灯具阵列：** 添加 4 条曲线分别对应 4 台灯具的空间轨迹，共用周期 10 s 循环闭合，4 个输出端口分别接到各灯具的位置参数，一次启动同步环绕。
**主从运动：** 曲线 1 为摄像机路径、曲线 2 为被摄目标轨迹，两条曲线共享同一播放头，VECTOR 输出分别驱动摄像机与目标，保持相对构图恒定。
**时间线同步：** TimeLineNode 的 SYNC 输出接到 SYNC 端口，全部曲线运动与时间线播放头严格对齐（按周期取模映射）。
