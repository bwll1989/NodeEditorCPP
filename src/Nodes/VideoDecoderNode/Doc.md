# Video Decoder

## 1. 节点说明

播放媒体库中的视频文件（FFmpeg 解码），输出视频帧和多路音频。内部为双 `AVFormatContext` + 三线程模型（audioLoop / videoLoop 两条 std::thread + GUI 线程 GPU 上传），音视频各一条独立读包链路互不阻塞。输出音频端口数随文件的声道数自动增减；纯视频文件时只保留 Image 端口。

视频帧写入共享 GPU 纹理环形队列（`ImageTimestampRingQueue`，默认 8 槽），下游按帧时钟拉取最新帧，无逐帧 `dataUpdated` 推送；音频经重采样到 48000 Hz float 后按声道拆分写入各声道共享环形队列。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 4 | 是 | 4 | 4 | — | 无 |
| 输出 | 3 | 是 | 1 | — | AudioData | 1 个 Image + N 个音频声道口；加载文件后按实际声道数自动增删（1+声道数） |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。
> 注意：输出端口数由加载的媒体文件决定（换文件时按 1+声道数重建），手动增删会被覆盖。

### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | PLAY/STOP | VariableData | 布尔：true 播放（从文件头开始），false 停止 |
| 1 | STOP | VariableData | 布尔：仅 true 时停止播放，false 无动作 |
| 2 | LOOP | VariableData | 布尔：是否循环播放 |
| 3 | GAIN | VariableData | 数值：音量增益，单位 dB |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | Image | ImageData | 当前视频帧（共享纹理环形队列句柄，下游按帧时钟拉取） |
| 1…N | CH 1、CH 2… | AudioData | 各声道共享音频环形队列，数量随文件变化；无音频轨时无此组端口 |

## 3. 界面与属性

控件面板（`WidgetEmbeddable=false`，显示在右侧属性面板，不嵌入节点体）：

| 控件 | 说明 |
|------|------|
| 文件选择框 | SelectorComboBox，列出媒体库 Video 分类，选择即加载 |
| Play 按钮 | 可勾选按钮，切换播放/停止 |
| 进度条 | 仅显示播放进度（0–1000），不可拖动定位 |
| 时间标签 | `当前 / 总时长`（m:ss 格式） |
| Loop 复选框 | 循环开关 |
| 音量滑块 | -40 ~ +20 dB，步进 0.5，默认 -10 dB |

公开属性（Q_PROPERTY）：

| 属性 | 类型 | 说明 |
|------|------|------|
| `fileName` | string | 媒体库相对文件名，设置即加载 |
| `loop` | bool | 循环 |
| `volume` | double | 音量 dB（解码后 PCM 按线性增益 `10^(dB/20)` 缩放） |
| `play` | bool | 播放状态（与 Play 按钮同步） |

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/fileName` | 可写（**实际无效**） | 已注册绑定并订阅 Command，但处理分支比较的键名为 `file`，与订阅地址不匹配——外部写入不生效，文件只能从界面选择 |
| `/loop` | 可写 | 循环开关（payload 转布尔） |
| `/volume` | 可写 | 音量 dB（payload 转数值） |
| `/play` | 可写 | true 播放 / false 停止（payload 转布尔） |
| `/stop` | **无效** | 源码已订阅该地址，但处理函数中没有 `stop` 分支，写入被忽略 |

外部播放控制请写 `/play=false`。加载失败、未加载时 `play` 属性反馈 false。

## 5. 行为细节

- **播放语义**：开始播放前先 `stopPlay` 再 `startPlay`，**总是从文件头重新开始**（无暂停续播）；未成功加载文件（`!isReady`）时播放请求被忽略。非循环模式自然播放到末尾自动置为停止（主动停止不触发完成回调）。
- **换源续播**：播放中切换文件会先清空视频环形队列（不保留旧帧），加载成功后自动续播新文件。
- **加载失败**：`initializeFFmpeg` 失败时节点标记未就绪、强制反馈停止状态。
- **视频链路**：videoLoop 读包→解码→PTS 节流→sws_scale 转 BGRA→双缓冲 swap→投递 GUI 线程上传 GPU 纹理→push 到共享环形队列；上传期间若解码线程又产出新帧则合并调度，只保留最新帧。构造时在 GUI 线程预热离屏表面（`ImageGpuUpload::warmup`），避免解码首帧缺上下文。
- **音频链路**：swr 重采样到统一 48000 Hz / float（44100 等源自动重采样）→按系统帧率切成固定块→拆分声道→push 到各声道共享环形队列。
- **进度反馈**：有音频时由音频链路驱动（约 100ms 节流），纯视频由视频 PTS 驱动；驱动进度条与时间标签显示。
- **端口自适应**：加载成功后输出端口数调整为 1+声道数，增删以框架端口事件通知（下游连线索引随之变化）。
- **持久化**：顶层键 `filePath`（媒体库相对文件名）、`isLoop`、`volume`、`play`、`autoPlay`（两者均写当前播放状态）；加载时兼容 `play` 或 `autoPlay` 键，恢复音量/循环/文件后，若文件存在于媒体库则延迟 100ms 应用播放状态（等待解码器就绪），即保存时正在播放的工程重开后会自动续播。
- **析构**：播放中先停止解码并等待线程退出。

## 6. 使用说明与典型接法

1. 从媒体库下拉框选择视频文件（也可由工程文件恢复）。
2. 点击 Play 或向 PLAY/STOP 端口送布尔控制播放；GAIN 端口接 Variable 控制音量（dB）。
3. Image 接 WindowDisplay / ImageShow / NDI Out 等；CH n 接 Audio Device Out 等音频输出。
4. 循环播放勾选 Loop 或 LOOP 端口置 true；外部停止用 `/play=false`。

## 7. 示例

Video Decoder → Image → Window Display、CH1/CH2 → Audio Device Out，实现音视频同步播放；再从节点 OSC 地址 `/play`、`/volume` 接入控台场景切换，`/loop` 接循环展项控制。
