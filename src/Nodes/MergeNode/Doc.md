# Merge

## 1. 节点说明

Merge 将**多个输入端口**上的 VariableData，按行规则**合并为一个**键值对象输出。每一行对应一个输入端口：指定从该端口数据读取哪个字段名，以及写入输出对象时使用的键名（可重命名）。

适合把多路来源拼成一条消息供下游脚本或网络发送。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 4 | 是 | 1 | 不限 | VariableData | 行列表驱动（+ / 删除增删端口，不走 PortEdit） |
| 输出 | 1 | 否 | 1 | 1 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0…N-1（默认 4 个） | INPUT 0 … | VariableData | 与 UI 行一一对应；通过 **+ / 删除** 增减，不可再走 PortEdit |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | OUTPUT 0 | VariableData | 合并后的键值对象 |

## 3. 界面与属性

控件面板（`WidgetEmbeddable=false`，显示在右侧属性面板，不嵌入节点体）每行对齐一个输入端口（`PortAlignedColumn`）：

| 控件 | 含义 |
|------|------|
| Name | 从该行对应端口的 VariableData 中读取的字段名 |
| Rename | 写入输出对象时使用的键名；**留空**则与 Name 相同 |
| 删除 | 删除该行及其对应输入端口，其后端口与连线向上补位（最少保留 1 行） |
| + | 在末尾增加一行与一个输入端口 |

任一输入或行内容变更会重新计算输出。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

本节点未注册任何专属 OSC 地址（源码无 `Q_PROPERTY` 外部属性、无 `registerExternalBinding` 调用），也不接收外部 Command；行配置只能在内嵌面板中编辑。

## 5. 行为细节

- **按端口缓存**：每个输入端口的 VariableData 按端口索引缓存在 `in_dictionary` 中，任一输入到达或断开都触发整表重算。
- **断开即剔除**：某端口断开（数据为空）时从缓存中移除该端口条目并重算，输出对象中不再包含该行字段。
- **逐行合并规则**：行未对应数据、或 Name 为空 → 跳过该行；Rename 留空则沿用 Name 作为输出键；字段值从该端口数据的 `value(name)` 取出后写入输出对象。
- **删行补位**：删除某行后，其后输入端口的缓存按新索引上移，与连线自动补位一致。
- **整表重算**：单行内容变更（如改 Rename）也走整表重算，避免改键后残留旧键。
- **持久化**：行配置保存在 `values.key`（内含 `rows` 数组，`ID` 为行/端口索引）；`load()` 按行序恢复，并把输入端口数重设为实际行数（最少 1）。

## 6. 使用说明与典型接法

1. 用 + / 删除调整输入端口数量（每行一个端口）。
2. 为每行填写 Name（源字段）、Rename（可选）。
3. 将多路数据接到对应 INPUT。
4. 从 OUTPUT 0 取合并结果。

若某行对应端口尚无数据，或 Name 为空，该行会被跳过。

配置仍保存在 `values.key`（内含 `rows` 数组；`ID` 为行/端口索引，加载时按行序对齐）。

## 7. 示例

| 行/端口 | Name | Rename | 效果 |
|---------|------|--------|------|
| 0 | `x` | `posX` | 端口 0 的 `x` → 输出 `posX` |
| 1 | `y` | `posY` | 端口 1 的 `y` → 输出 `posY` |
| 2 | `label` | （空） | 端口 2 的 `label` → 输出 `label` |

两路位置与一路标签合并后，接 OSC Out 或 JavaScript 节点。
