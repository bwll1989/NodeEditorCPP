# Merge

## 1. 节点说明

Merge 将**多个输入端口**上的 VariableData，按行规则**合并为一个**键值对象输出。每一行对应一个输入端口：指定从该端口数据读取哪个字段名，以及写入输出对象时使用的键名（可重命名）。

适合把多路来源拼成一条消息供下游脚本或网络发送。

## 2. 端口说明

### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0…N-1（默认 4 个） | INPUT 0 … | VariableData | 与 UI 行一一对应；通过 **+ / 删除** 增减，不可再走 PortEdit |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | OUTPUT 0 | VariableData | 合并后的键值对象 |

## 3. 界面说明

嵌入区每行对齐一个输入端口（`PortAlignedColumn`）：

| 控件 | 含义 |
|------|------|
| Name | 从该行对应端口的 VariableData 中读取的字段名 |
| Rename | 写入输出对象时使用的键名；**留空**则与 Name 相同 |
| 删除 | 删除该行及其对应输入端口，其后端口与连线向上补位 |
| + | 在末尾增加一行与一个输入端口 |

任一输入或行内容变更会重新计算输出。

## 4. 使用说明

1. 用 + / 删除调整输入端口数量（每行一个端口）。
2. 为每行填写 Name（源字段）、Rename（可选）。
3. 将多路数据接到对应 INPUT。
4. 从 OUTPUT 0 取合并结果。

若某行对应端口尚无数据，或 Name 为空，该行会被跳过。

配置仍保存在 `values.key`（内含 `rows` 数组；`ID` 为行/端口索引，加载时按行序对齐）。

## 5. 示例

| 行/端口 | Name | Rename | 效果 |
|---------|------|--------|------|
| 0 | `x` | `posX` | 端口 0 的 `x` → 输出 `posX` |
| 1 | `y` | `posY` | 端口 1 的 `y` → 输出 `posY` |
| 2 | `label` | （空） | 端口 2 的 `label` → 输出 `label` |

两路位置与一路标签合并后，接 OSC Out 或 JavaScript 节点。
