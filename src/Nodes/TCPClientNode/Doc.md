# TCP Client

## 1. 节点说明

TCP 客户端节点，主动连接指定服务器并收发数据。适合连接第三方 TCP 服务、PLC 网关或本机其他程序的 TCP 端口。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 4 | 否 | 4 | 4 | — | 末端口为 TRIGGER（发送触发） |
| 输出 | 4 | 否 | 4 | 4 | — | 末端口为 HEX（十六进制） |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 名称 | 说明 |
|------|------|------|
| 0 | HOST | 设置服务器 IP 或主机名 |
| 1 | PORT | 设置服务器端口 |
| 2 | VALUE | 设置发送内容并立即发送 |
| 3 | TRIGGER | 输入为 `true` 时，按当前 **value** 发送 |

### 输出

| 端口 | 名称 | 说明 |
|------|------|------|
| 0 | RESULT | 完整接收消息 |
| 1 | HOST | 当前连接的服务器地址 |
| 2 | VALUE | 当前发送/接收的文本（VALUE 输出为界面保存值） |
| 3 | HEX | 接收数据的十六进制形式 |

## 3. 界面与属性

节点控件面板（`WidgetEmbeddable=false`，显示在右侧属性面板，不嵌入节点体）：

| 控件 | 说明 |
|------|------|
| Host（行编辑框） | 服务器地址，默认 `127.0.0.1`；编辑完成即重连 |
| Port（数字拖动框） | 服务器端口，默认 `2001`；变更即重连 |
| value（行编辑框） | 发送内容；编辑完成立即按当前格式发送 |
| Format（下拉框） | 发送编码：HEX / UTF-8 / ASCII |
| 状态按钮 | **只读**显示 Connected / Disconnect（绿/红），不可点击切换连接 |
| Send（按钮） | 按当前 value 与格式发送，仅已连接时可用 |

节点公开 4 个 `Q_PROPERTY`：

| 属性 | 类型 | 说明 |
|------|------|------|
| `host` | QString | 服务器地址（变更即重连） |
| `port` | int | 服务器端口（变更即重连） |
| `value` | QString | 发送内容（赋值即发送） |
| `connected` | bool | 连接状态（只读回读，写无效） |

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/host` | 可写（命令） | 字符串，改服务器地址并立即重连 |
| `/port` | 可写（命令） | 整型，改端口并立即重连 |
| `/value` | 可写（命令） | 字符串，设置发送内容并**立即发送** |
| `/connected` | 可写（命令） | 布尔，已订阅但 `setConnected` 为空操作，**外部写入被忽略**；仅作状态回读（真实状态来自 socket 回调） |
| `/send` | 可写（命令） | 触发一次发送；模型回发 `/send` true→false 脉冲状态反馈 |

`host`/`port`/`value`/`connected`/`send` 均通过 `registerExternalBinding` 注册（绑定界面控件）并订阅 Command 事件。

## 5. 行为细节

- **线程模型**：socket 在独立工作线程中创建与收发（TcpClientWorker），模型层全部通过队列信号交互，不阻塞 GUI。
- **连接语义**：`host`/`port` 任一变更即「停重连定时器 → abort 旧连接 → 连新地址」；连接失败或对端断开时自动启动 **1s 周期重连**，连上后停止；主动断开则不重连。
- **发送**：按 Format 编码（HEX=`QByteArray::fromHex`、UTF-8、ASCII/Latin1）；未连接时消息**直接丢弃**并告警。发送动作伴随 `/send` true→false 脉冲反馈。
- **VALUE 自动发送**：`value` 属性赋值即触发发送（不去重）——VALUE 端口、`/value`、界面编辑完成都会立即发出，即使内容与上次相同。
- **接收**：每条消息打包为 QVariantMap `{host（对端地址）, hex, utf-8, ascii, default（原始字节）}` 推给 RESULT，同时刷新 HOST/VALUE/HEX 三路输出。
- **端口连接策略**：所有输入、输出端口均可连多路（Many/Many）。
- **持久化**：`values.Port`、`values.IP`、`values.Value`、`values.Format`（键名首字母大写）；加载后恢复 host/port/value 并按保存的 Format 索引恢复编码选择。

## 6. 使用说明与典型接法

1. 填写 **Host** 和 **port**；修改后会自动尝试连接。
2. 连接成功后从 **RESULT** 等端口获取服务器回传数据。
3. 通过 **value** + **Send**，或 **VALUE** / **TRIGGER** 输入端口发送。
4. 工程会保存 IP、端口、发送格式等配置。

## 7. 示例

- **查询设备状态**：**value** 写 `GET_STATUS\r\n`，连 **TRIGGER** 定时触发。
- **联动上游**：字符串节点 → **VALUE**，每次变量更新自动发到服务器。
- **远程切换服务器**：OSC 写 `/dataflow/Scene/8/host` 为 `192.168.1.100`，写 `/port` 为 `502`，节点自动重连。
