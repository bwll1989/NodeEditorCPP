# Audio Delay

## 1. 节点说明

多路音频**时间戳延时**：PCM 原样透传，仅把每帧输出时间戳加上 **Delay** 帧数。用于补偿不同路径上的固定延时差（例如一侧经过矩阵/混音多了「音频输出延时」，另一侧直连时可用本节点对齐）。

## 2. 端口说明

用 **Channels** 配置路数（1–64，默认 1），输入与输出一一对应。

### 输入

- **In 1 … In N**（AudioData）：节目通道，可为单声道或多声道交错 PCM。

### 输出

- **Out 1 … Out N**（AudioData）：与各 In 对应；内容相同，时间戳 = 输入时间戳 + Delay。

## 3. 参数

- **Channels**（1 ~ 64）：通道数。
- **Delay**（0 ~ 64 帧）：输出时间戳后移量。系统时钟约 50 Hz，1 帧 ≈ 20 ms。

也可通过 OSC `/delay` 或 `/delay_frames` 设置延时帧数。

## 4. 使用说明

1. 用 Channels 设好路数。
2. 较短路径接到 In，Out 接下级或声卡；把 Delay 调到与另一路固定延时一致。
3. 例如设置里「音频输出延时」为 2 帧、某路经 Matrix 已自动加 2 帧，直连路可在本节点设 Delay = 2 对齐。
