# Keyboard In

## 1. 节点说明

Keyboard In 以列表监视应用程序内按键状态（按下 = `1`，松开 = `0`），行为对齐 [TouchDesigner Keyboard In CHOP](https://docs.derivative.ca/index.php?title=Keyboard_In_CHOP)。

每一行对应一个输出端口；用左侧 **+** / 行内删除增减，无需再填 Index。

本节点不会注册系统全局热键，不会抢走按键。

## 2. 端口说明

### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | ENABLE | VariableData | 使能监视；与左侧 **On** 为同一状态（端口写入会同步复选框；断开后保持当前 On） |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 … N-1（默认 4） | K0 … | VariableData | 该行按键状态 `0/1`；与 UI 行一一对应 |

## 3. 界面说明

- **左侧**（加宽、按行距排布）：`+`、**On**（与 ENABLE 同一使能）、**Mod** 下拉（修饰键过滤）
- **右侧**：每行对齐一个输出端口 — 删除、按键录制

## 4. 使用说明

1. 用 + / 删除调整输出端口数量。
2. 在对应行录制按键；可选接入 ENABLE 做外部开关。
3. 边沿触发可接 Edge Trigger；按住电平直接使用 `0/1`。

# Mouse In

## 1. 节点说明

Mouse In 监视鼠标位置与左/右键。

与 Keyboard In 同属 Controls 插件；不拦截鼠标事件，其它界面可正常操作。

## 2. 端口说明

### 输入

无。

### 输出

| 端口 | 名称 | 说明 |
|------|------|------|
| 0 | tx | X 坐标（像素或归一化） |
| 1 | ty | Y 坐标（像素或归一化） |
| 2 | left | 左键 0/1 |
| 3 | right | 右键 0/1 |
| 4 | pos | VariableData，`default` 为 `[tx, ty]` |

## 3. 界面说明

- **Active**：总开关
- **Coord**：`Absolute`（屏幕像素）/ `Normalized`（当前屏幕 0–1）
- 通道预览（FloatDrag，只读，与端口同名）：`tx` / `ty` / `left` / `right`

## 4. 使用说明

1. 勾选 Active，选择坐标模式。
2. 将 `tx`/`ty` 接到下游做跟随；按键通道做点击触发。

**注意：** 位置与按键通过轮询全局状态。
