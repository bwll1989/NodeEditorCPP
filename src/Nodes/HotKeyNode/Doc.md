# Keyboard In

## 1. 节点说明

Keyboard In 以列表监视应用程序内按键状态（按下 = `1`，松开 = `0`），行为对齐 [TouchDesigner Keyboard In CHOP](https://docs.derivative.ca/index.php?title=Keyboard_In_CHOP)。

每一行对应一个输出端口；用左侧 **+** / 行内删除增减，无需再填 Index。

本节点不会注册系统全局热键，不会抢走按键；监视范围为 Flow 应用程序内（窗口未聚焦时收不到键盘事件）。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 1 | 否 | 1 | 1 | — | 无 |
| 输出 | 4 | 否 | 1 | — | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。
> 输出端口数量由界面行数驱动：点击 **+** 增行、行内删除按钮删行（最少保留 1 行），行索引即端口索引；增删行走框架端口插入/删除事件。

### 输入

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | ENABLE | VariableData | 使能监视；与左侧 **On** 为同一状态（端口写入会同步复选框；断开后保持当前 On） |

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 … N-1（默认 4） | K0 … | VariableData | 该行按键状态 `0/1`；与 UI 行一一对应，未激活时恒为 `0` |

## 3. 界面与属性

控件（`WidgetEmbeddable=false`，显示在右侧属性面板，不嵌入节点体）：

| 控件 | 默认 | 说明 |
|------|------|------|
| + 按钮 | — | 追加一行按键，同时新增一个输出端口 |
| On | 勾选 | 使能监视（与 ENABLE 输入同一状态）；关闭时所有按下行立即释放并推送 `0` |
| Mod | Ignore | 修饰键过滤：Ignore / None / Ctrl / Alt / Ctrl+Alt / Shift / Shift+Alt / Shift+Ctrl / Shift+Ctrl+Alt |
| 按键行（每行） | — | 删除按钮 + 按键录制框（QKeySequenceEdit，最多录 1 个组合）；行索引即输出端口索引 |

本节点无 Q_PROPERTY 外部属性。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

本节点未注册任何专属 OSC 地址（源码无 `Q_PROPERTY` 外部属性、无 `registerExternalBinding` 调用），不能通过 OSC/网页等方式远程读写；按键使能与状态只能在本节点界面操作，或经 ENABLE 输入端口控制。

## 5. 行为细节

- **监视方式**：对 QApplication 安装全局事件过滤器，只处理 KeyPress / KeyRelease；忽略自动重复（长按不重复触发）；不注册系统全局热键，不消费按键事件。
- **录制互斥**：当前焦点控件是 QKeySequenceEdit（正在录制）时不监视，避免录入过程误触发。
- **修饰键过滤**：按 Mod 下拉的 9 种模式精确匹配当前 Ctrl/Alt/Shift 组合（Ignore 模式忽略修饰键）；修饰键不匹配时释放所有已按下行。
- **匹配规则**：仅比对录制序列第一组按键的键值（`sequence[0].key()`）——录制 `Ctrl+A` 实际监视的是 A 键本身，Ctrl 部分由 Mod 过滤器负责。
- **状态输出**：行按下 = `1`、松开 = `0`（VariableData）；仅状态变化时对该端口推送一次 `dataUpdated`；On 关闭时所有行恒输出 `0`。
- **行与端口**：+ 增行 / 行内删除删行（最少 1 行）分别触发端口插入/删除事件；删行后对所有剩余输出重发一次当前状态。
- **ENABLE 输入**：有数据时按 `default` 布尔值同步 On 复选框（阻断复选框信号防回环）；断开连接保持当前 On；每次写入后重发所有输出。
- **持久化**：顶层键 `active`（默认 true）、`modifiers`（int）、`keys`（数组，每项 `{port, value}`）；兼容旧版固定 5 路 `hotkey1…hotkey5`；加载后按行数同步输出端口数。
- **应用级而非系统级**：仅在 Flow 窗口持有焦点时能收到键盘事件；按键被其它窗口/网页占用时监视不到。

## 6. 使用说明与典型接法

1. 用 + / 删除调整输出端口数量。
2. 在对应行录制按键；可选接入 ENABLE 做外部开关。
3. 边沿触发可接 Edge Trigger；按住电平直接使用 `0/1`。

## 7. 示例

Keyboard In 录制空格 → K0 → Edge Trigger → 触发 Cue 播放；或 K0 电平直接接混合节点做"按住才生效"的通道开关。多行可同时监视多个按键，互不影响。

# Mouse In

## 1. 节点说明

Mouse In 监视鼠标位置与左/右键。

与 Keyboard In 同属 Controls 插件；不拦截鼠标事件，其它界面可正常操作。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 0 | 否 | 0 | 0 | — | 无 |
| 输出 | 5 | 否 | 5 | 5 | — | 末端口为 Pos（[tx,ty] 聚合输出）；5 口固定：Tx/Ty/Left/Right/Pos |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。

### 输入

无。

### 输出

| 端口 | 名称 | 数据类型 | 说明 |
|------|------|----------|------|
| 0 | tx | VariableData | X 坐标（像素或 0–1 归一化） |
| 1 | ty | VariableData | Y 坐标（像素或 0–1 归一化） |
| 2 | left | VariableData | 左键 `0/1` |
| 3 | right | VariableData | 右键 `0/1` |
| 4 | pos | VariableData | 聚合输出，`default` 为 `[tx, ty]` |

## 3. 界面与属性

控件（`WidgetEmbeddable=false`，显示在右侧属性面板，不嵌入节点体）：

| 控件 | 默认 | 说明 |
|------|------|------|
| Active | 勾选 | 总开关；关闭即停止轮询（数值保持最后状态，不归零） |
| Coord | Absolute | `Absolute`（屏幕像素）/ `Normalized`（光标所在屏幕 0–1） |
| tx / ty 预览 | 只读 | FloatDrag 只读显示（透明鼠标事件），像素 0 位小数、归一化 4 位 |
| left / right 预览 | 只读 | 0/1 只读显示 |

本节点无 Q_PROPERTY 外部属性。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

本节点未注册任何专属 OSC 地址（源码无 `Q_PROPERTY` 外部属性、无 `registerExternalBinding` 调用），不能通过 OSC/网页等方式远程读写；只能在本节点界面开关监视与切换坐标模式。

## 5. 行为细节

- **轮询采样**：16 ms QTimer（约 60 Hz）轮询全局鼠标状态，不安装事件过滤器、不消费任何鼠标事件。
- **坐标**：`QCursor::pos()` 全局像素；Normalized 模式换算到光标所在屏幕（`screenAt`，找不到回落主屏）几何范围内的 0–1；两屏之间/屏幕外取主屏。切换 Coord 立即重采样并切换预览小数位（归一化 4 位、像素 0 位）。
- **按键**：Windows 用 `GetAsyncKeyState(VK_LBUTTON/VK_RBUTTON)` 全局检测（焦点不在 Flow 也能取到）；其它平台用 `QGuiApplication::mouseButtons()`。
- **变化推送**：tx/ty 用浮点近似比较，按键用布尔比较；仅变化的端口推送（tx 或 ty 变化时 pos 跟随推送）；无变化不推送。
- **Active**：关闭即停轮询（tx/ty/按键保持最后值，不归零）；重新勾选立即采样一次。
- **持久化**：顶层键 `active`（默认 true）、`coord`（0=Absolute，1=Normalized）。

## 6. 使用说明与典型接法

1. 勾选 Active，选择坐标模式。
2. 将 `tx`/`ty` 接到下游做跟随；按键通道做点击触发。

**注意：** 位置与按键通过轮询全局状态。

## 7. 示例

Mouse In（Normalized）→ pos → 坐标换算 → 窗口/图层位置参数：实现展项大屏上的鼠标跟随光标；left → Edge Trigger 可做点击拍照、点击交互触发。
