# FT-C040A

## 1. 节点说明

> ⚠️ **版本要求**：本节点为 **Advance（进阶版）** 功能，需有效授权后才能加载使用。

用于控制软方C040A触摸屏，模拟modbus从机，与触摸屏进行通讯。
**FT-C040A** 作为 **Modbus TCP 从机（Slave）**，在本机监听端口，响应主机（如 Open ModScan）的读/写线圈请求。内部模拟 **16 路线圈**，PDU 地址为 **0001～0016**，并与界面勾选框、触摸屏外部控制、输出端口同步。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 3 | 否 | 3 | 3 | — | 无 |
| 输出 | 16 | 否 | 16 | 16 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 类型 | 说明 |
|------|------|------|
| HOST | VariableData | 监听地址（如 `0.0.0.0`） |
| PORT | VariableData | 监听端口（默认 `50001`） |
| ID | VariableData | Modbus 从站 ID（默认 `1`） |

### 输出

| 端口 | 类型 | 说明 |
|------|------|------|
| 0001～0016 | VariableData | 布尔值，对应当前线圈状态（含主机写入后的结果） |

## 3. 界面与属性

控件位于右侧属性面板（`WidgetEmbeddable=false`，不嵌入节点体）：

- **监听地址 / 端口 / 从站 ID**：TCP 从机参数（默认 `0.0.0.0:50001`，从站 ID `1`；也可改为 `502`）。变更即重启监听。
- **监听状态**：服务是否已成功 listen（`listening` 属性）。
- **0001～0016**：本地勾选可改线圈；主机写入时同步刷新。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/host` | 读/写 | 监听地址（Command payload 转字符串，变更后重启监听） |
| `/port` | 读/写 | 监听端口（payload 转 int） |
| `/serverId` | 读/写 | Modbus 从站 ID（payload 转 int） |
| `/listening` | 只读 | 监听状态（注册了属性绑定，模型就绪时推送初始值；未订阅 Command，不可外部写） |
| `/0001`～`/0016` | 读/写 | 线圈状态（payload 转 bool；写即 `stateFeedBack` 回读脉冲） |

## 5. 行为细节

- **输入语义**：HOST 端口 `asString()`、PORT 端口 `asInt()`、ID 端口 `asInt()`，设置后立即重启 TCP 监听。
- **Modbus 协议**：

| 类型 | 地址范围 | 读 | 写 |
|------|----------|----|----|
| 线圈 | `0001`～`0016`（PDU 1～16） | FC `0x01` 读线圈 | FC `0x05` 写单线圈；FC `0x0F` 写多线圈 |

- 主站起始地址填 **1**（显示常为 `000001` / `0001`），对应本节点第一路线圈。
- 写单线圈：`0xFF00` = ON，`0x0000` = OFF。
- 非法地址/数量/功能码返回标准 Modbus 异常响应；MBAP 事务 ID 原样返回。
- **同步路径**：无论线圈由界面勾选、OSC 写入还是主机 FC05/FC0F 写入，统一走 `setCoil` → 更新输出端口数据 + `stateFeedBack("/000N")` + 刷新界面勾选。
- **持久化**：`values.host` / `values.port` / `values.serverId`；监听状态与 16 路线圈状态**不持久化**（加载后线圈全为关）。

## 6. 使用说明与典型接法

1. 放置节点后确认监听成功（状态为绿色「监听中」）；也可通过 HOST/PORT/ID 输入端口动态改参数。
2. Open ModScan 连接本机 IP，端口与节点一致（默认 **50001**），设备地址 = 从站 ID。
3. 功能码选 **01 Coil Status**，起始地址设为 **1**，长度设为 **16**（或更小）。
4. 勾选界面 0001～0016 / 触摸屏写 `/0001`～`/0016`，主站下次轮询即可读到；输出端口同步给出当前状态。
5. 主站用 FC05/FC0F 写线圈后，界面与输出端口会同步更新。
