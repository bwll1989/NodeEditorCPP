# FT-C040A

## 1. 节点说明
用于控制软方C040A触摸屏，模拟modbus从机，与触摸屏进行通讯。
**FT-C040A** 作为 **Modbus TCP 从机（Slave）**，在本机监听端口，响应主机（如 Open ModScan）的读/写线圈请求。内部模拟 **16 路线圈**，PDU 地址为 **0001～0016**，并与界面勾选框、触摸屏外部控制、输出端口同步。

## 2. 端口说明

### 输入

| 端口 | 类型 | 说明 |
|------|------|------|
| HOST | VariableData | 监听地址（如 `0.0.0.0`） |
| PORT | VariableData | 监听端口（默认 `50001`） |
| ID | VariableData | Modbus 从站 ID（默认 `1`） |

### 输出

| 端口 | 类型 | 说明 |
|------|------|------|
| 0001～0016 | VariableData | 布尔值，对应当前线圈状态（含主机写入后的结果） |

## 3. 界面说明

- **监听地址 / 端口 / 从站 ID**：TCP 从机参数（默认 `0.0.0.0:50001`，从站 ID `1`；也可改为 `502`）。
- **监听状态**：服务是否已成功 listen。
- **0001～0016**：本地勾选可改线圈；主机写入时同步刷新。

外部控制地址：`/host`、`/port`、`/serverId`、`/listening`、`/0001`～`/0016`。

## 4. Modbus 地址与功能码

| 类型 | 地址范围 | 读 | 写 |
|------|----------|----|----|
| 线圈 | `0001`～`0016`（PDU 1～16） | FC `0x01` 读线圈 | FC `0x05` 写单线圈；FC `0x0F` 写多线圈 |

说明：

- 主站起始地址填 **1**（显示常为 `000001` / `0001`），对应本节点第一路线圈。
- 写单线圈：`0xFF00` = ON，`0x0000` = OFF。
- 非法地址/数量/功能码会返回标准异常响应。

## 5. 使用说明

1. 放置节点后确认监听成功（状态为绿色「监听中」）；也可通过 HOST/PORT/ID 输入端口动态改参数。
2. Open ModScan 连接本机 IP，端口与节点一致（默认 **50001**），设备地址 = 从站 ID。
3. 功能码选 **01 Coil Status**，起始地址设为 **1**，长度设为 **16**（或更小）。
4. 勾选界面 0001～0016 / 触摸屏写 `/0001`～`/0016`，主站下次轮询即可读到；输出端口同步给出当前状态。
5. 主站用 FC05/FC0F 写线圈后，界面与输出端口会同步更新。

## 6. 示例（Open ModScan）

| 项 | 建议值 |
|----|--------|
| IP | 本机 / 运行程序的电脑 IP |
| 端口 | `50001` |
| 设备地址 | `1` |
| 功能 | `01: COIL STATUS` |
| 起始地址 | `1` |
| 长度 | `16` |

勾选节点上的 `0003`，ModScan 中对应点应变为 `1`，同时输出端口 `0003` 变为 `true`。
