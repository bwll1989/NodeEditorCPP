# Serial Port

## 1. 节点说明

> ⚠️ **版本要求**：本节点为 **Advance（进阶版）** 功能，需有效授权后才能加载使用。

串口收发节点，用于与外部设备通过串口通信。可自动打开串口、发送数据，并将收到的数据从输出端口送出。适合控制舞台设备、传感器、单片机等串口设备。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 2 | 否 | 2 | 2 | — | 末端口为 TRIGGER（发送触发） |
| 输出 | 1 | 否 | 1 | 1 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 名称 | 说明 |
|------|------|------|
| 0 | VALUE | 收到数据后写入发送内容，并立即发送 |
| 1 | TRIGGER | 收到数据后立即按当前界面内容发送（不修改发送文本） |

### 输出

| 端口 | 名称 | 说明 |
|------|------|------|
| 0 | REC | 收到串口数据时输出 VariableData（含多种编码格式的字段） |

## 3. 界面与属性

控件面板（`WidgetEmbeddable=false`，显示在右侧属性面板，不嵌入节点体）：

| 控件 | 含义 |
|------|------|
| Port | 选择串口；**Refresh Ports** 刷新本机可用串口列表 |
| Baud Rate | 波特率（1200～921600，默认 9600） |
| Data Bits / Parity / Stop Bits | 数据位、校验、停止位；修改后重新打开串口 |
| Value | 待发送的文本内容 |
| Format | 发送编码：HEX、UTF-8、ASCII |
| Connected / Disconnect | 连接状态指示（只读，绿色为已连接） |
| Send | 手动发送；仅连接成功时可点 |

可外部控制的属性（Q_PROPERTY）：`port`、`baudRate`、`value`、`connected`（只读）。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/port` | 读写 | 串口名（如 `COM3`），修改后重新打开串口 |
| `/baudRate` | 读写 | 波特率（整数），修改后重新打开串口 |
| `/value` | 读写 | 发送内容（仅更新缓存，不自动发送） |
| `/send` | 命令 | 触发发送；执行时 `/send` 短暂反馈 `true` 再恢复 `false` |
| `/connected` | 只读状态 | 连接状态（未订阅有效 Command——外部写会被忽略，仅随实际连接状态回读） |

## 5. 行为细节

- **串口线程**：打开、关闭、收发均经队列调用在串口设备线程执行，界面不阻塞；构造完成后按当前参数自动打开串口。
- **参数变更即重开**：port、baudRate、数据位、校验、停止位任一变化都会以新参数重新打开串口。
- **端口语义**：VALUE 更新发送内容并**立即发送**；TRIGGER 按当前内容直接发送（不改文本）；断开输入不动作。
- **发送编码**：按 Format 下拉（HEX / UTF-8 / ASCII）编码后写出。
- **接收输出**：收到串口数据时 REC 输出键值对象（设备层提供多种编码格式的字段），每次接收刷新输出。
- **连接策略**：所有端口均为 Many。
- **持久化**：`save()` 将 `Port`、`BaudRate`、`Value`、`DataBits`、`Parity`、`StopBits`、`Format` 写入 `values.*`（键名首字母大写）；`load()` 恢复后重新打开串口。
- **资源清理**：析构时关闭串口并释放设备。

## 6. 使用说明与典型接法

1. 将节点拖入画布，选择正确串口与波特率；节点加载后会尝试自动打开串口。
2. 在 **Value** 填写要发送的内容，选择 **Format**，点击 **Send** 或从 **VALUE** / **TRIGGER** 端口触发发送。
3. 将 **REC** 连到下游节点，处理接收数据。
4. 修改串口参数后节点会重新打开串口；工程保存时会记住端口、波特率、帧格式等设置。

## 7. 示例

- **按钮触发发送**：Inject 节点输出 `true` 到 **TRIGGER**，串口按当前 **Value** 发送固定指令。
- **动态内容**：上游字符串节点连到 **VALUE**，每次更新自动发送新内容。
- **外部 OSC 控制**：向 `/dataflow/Show/12/value` 写入 `"01 FF 00"`，再向 `/dataflow/Show/12/send` 发命令，即可远程发十六进制串口包。
