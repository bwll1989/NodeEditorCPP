# RGBA

## 1. 节点说明

把输入解析为 **RGBA 浮点向量** `[r, g, b, a]`（维数不足补 0）。带色板。输出 HSV 向量、RGBA 向量以及 R/G/B。

默认 `[0, 0, 0, 1]`。工程保存 `rgba` 数组。

## 2. 端口

### 输入

| 端口 | 说明 |
|------|------|
| RGBA | 向量，按 RGBA 解析 |
| R / G / B / A | 单通道浮点 |

### 输出

| 端口 | 说明 |
|------|------|
| HSV | `[h, s, v]`（0～1） |
| RGBA | `[r, g, b, a]` |
| R / G / B | 分量 |

## 3. 外部控制

`/rgba`、`/red`、`/green`、`/blue`、`/alpha`

## 4. 示例

Vec Source → RGBA → TEXT_COLOR；或 HSV 口接条件。

# HSV

## 1. 节点说明

把输入解析为 **HSV 浮点向量** `[h, s, v]`（0～1，不足补 0）。带色板。输出 RGBA 向量（alpha 固定 1）、HSV 向量以及 H/S/V。

默认 `[0, 0, 0]`。工程保存 `hsv` 数组。

## 2. 端口

### 输入

| 端口 | 说明 |
|------|------|
| HSV | 向量，按 HSV 解析 |
| H / S / V | 单通道浮点 0～1 |

### 输出

| 端口 | 说明 |
|------|------|
| RGBA | `[r, g, b, 1]` |
| HSV | `[h, s, v]` |
| H / S / V | 分量 |

## 3. 外部控制

`/hsv`、`/hue`、`/saturation`、`/value`

## 4. 示例

HSV（改 H）→ RGBA → 其它颜色口；或 H 做色相分支。
