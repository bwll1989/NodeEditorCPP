# RGBA

## 1. 节点说明

把输入解析为 **RGBA 浮点向量** `[r, g, b, a]`（维数不足补 0）。带色板。输出 HSV 向量、RGBA 向量以及 R/G/B。

默认 `[0, 0, 0, 1]`。工程保存 `rgba` 数组。

## 2. 端口

### 输入

| 端口 | 说明 |
|------|------|
| RGBA | 向量，按 RGBA 解析 |
| R / G / B / A | 单通道浮点 |

### 输出

| 端口 | 说明 |
|------|------|
| HSV | `[h, s, v]`（0～1） |
| RGBA | `[r, g, b, a]` |
| R / G / B | 分量 |

## 3. 外部控制

`/rgba`、`/red`、`/green`、`/blue`、`/alpha`

## 4. 示例

Vec Source → RGBA → TEXT_COLOR；或 HSV 口接条件。

# HSV

## 1. 节点说明

把输入解析为 **HSV 浮点向量** `[h, s, v]`（0～1，不足补 0）。带色板。输出 RGBA 向量（alpha 固定 1）、HSV 向量以及 H/S/V。

默认 `[0, 0, 0]`。工程保存 `hsv` 数组。

## 2. 端口说明

| 方向 | 默认数量 | 可编辑 | 最小 | 最大 | 新增端口类型 | 末端口差异 |
|------|----------|--------|------|------|--------------|------------|
| 输入 | 4 | 否 | 4 | 4 | — | 无 |
| 输出 | 5 | 否 | 5 | 5 | — | 无 |

> 本表对应 .flow 中该节点的 `input-count` / `output-count` / `port-editable` 三个字段：
> AI 搭图时连接索引不能超过当前端口数，可编辑节点的取值范围由"最小/最大"给出。



### 输入

| 端口 | 说明 |
|------|------|
| HSV | 向量，按 HSV 解析 |
| H / S / V | 单通道浮点 0～1 |

### 输出

| 端口 | 说明 |
|------|------|
| RGBA | `[r, g, b, 1]` |
| HSV | `[h, s, v]` |
| H / S / V | 分量 |

## 3. 界面与属性

| 属性 | 类型 | 默认值 | 取值范围 | 说明 |
|------|------|--------|----------|------|
| hsv | QVariant | [0, 0, 0] | h/s/v 各 0～1 | 当前 HSV 颜色（数组保存），对应色板选区 |
| hue | double | 0 | 0～1 | 色相分量，OSC `/hue` |
| saturation | double | 0 | 0～1 | 饱和度，OSC `/saturation` |
| value | double | 0 | 0～1 | 明度，OSC `/value` |

内嵌界面控件：HSV 色板（点选/拖动设置颜色）。工程保存 `hsv` 数组并在加载时恢复。

## 4. 外部控制（OSC 地址）

地址前缀：`/dataflow/{别名}/{节点ID}/…`

| 地址 | 方向 | 说明 |
|------|------|------|
| `/hsv` | 读/写 | 绑定属性 `hsv`；写入负载经 `asFloats(3)` 解析为 `[h, s, v]` |
| `/hue` | 读/写 | 绑定属性 `hue`（0～1） |
| `/saturation` | 读/写 | 绑定属性 `saturation`（0～1） |
| `/value` | 读/写 | 绑定属性 `value`（0～1） |

## 5. 行为细节

- 输入 HSV 口按向量解析（不足 3 位补 0）；H/S/V 分量口按单通道浮点写入对应分量。
- 任一来源（色板、输入口、OSC）变更后，RGBA/HSV/H/S/V 全部输出同步刷新。
- 持久化：`save()` 保存 `hsv` 数组；`load()` 恢复并同步色板。

## 6. 使用说明与典型接法

HSV（改 H）→ RGBA → 其它颜色口；或 H 做色相分支。

## 7. 示例

同上：色板选色 → RGBA 输出驱动灯光/字幕颜色类节点。
