# ModBusMaster 插件

本插件包含两个 **Modbus TCP 主机** 节点：

1. **ModBus Coil Controller** — 读写线圈（FC01 / FC05），仅输入端口  
2. **ModBus Discrete Input** — 读取离散输入（FC02），仅输出端口  

---

# ModBus Coil Controller

## 1. 节点说明

通过 **Modbus TCP 主机** 读写从站设备上的线圈（Coil）。

节点内部维护两套状态：

| 状态 | 含义 |
|------|------|
| **期望状态**（节点侧） | 界面勾选框 / 输入端口 / OSC `/Cn` 写入的值，是同步的**权威来源** |
| **设备状态**（缓存） | 最近一次 `0x01` 读回或 `0x05` 写成功后的缓存，用于比对差异 |

数量、起始地址、地址基址（0/1 基）可配置；协议层始终按 **PDU（0 基）** 发命令。

## 2. 端口说明

### 输入

| 端口 | 类型 | 说明 |
|------|------|------|
| C0～CN-1 [addr] | VariableData | 布尔值，写入对应线圈**期望状态**；变化后立即对该路发 `0x05` |

无输出端口。

## 3. 界面说明

- **IP / 端口 / Server ID**：连接参数（默认 `127.0.0.1:502`）。
- **数量 / 起始地址**：1～64；地址基址可选 **0 基 (PDU)** 或 **1 基**（命令始终按 PDU 发送）。
- **线圈勾选框**：本地期望状态；勾选变化后立即写对应线圈。

外部控制：`/host`、`/port`、`/serverId`、`/coilCount`、`/addressBase`、`/coilStartAddress`、`/C0`～`/CN-1`。

## 4. 功能码

| 类型 | 读 | 写 |
|------|----|----|
| 线圈 | FC `0x01`（批量读整段） | FC `0x05`（单线圈写） |

## 5. 同步逻辑

**原则：始终以节点期望为准，把设备拉齐到节点，而不是把节点改成设备。**

### 5.1 连接成功时

1. 启动轮询定时器。  
2. **立即**按当前全部期望状态，对每一路线圈入队 `0x05` 写（不以设备首次读回覆盖本地）。  
3. 写命令串行发送，相邻指令间隔见下节「频率」。

### 5.2 空闲轮询（读）

当满足「已连接、无在途应答、命令队列为空、指令间隔定时器未在跑」时，约每 **100ms** 发一次 `0x01`，读取整段线圈并更新设备状态缓存。

### 5.3 读回发现不一致（写差异）

若某路「期望 ≠ 设备缓存」：

1. 丢弃队列中尚未发出的旧写命令（避免堆积过时目标）。  
2. **只对不一致的线圈** 重新入队 `0x05`。  
3. 仍按串行 + 指令间隔发送。

### 5.4 本地主动改写

界面勾选 / 输入端口 / OSC 改某一路期望值时：

1. 更新该路期望状态与界面。  
2. 若已连接，**立即**为该路入队一条 `0x05`（不必等下次 100ms 轮询）。

### 5.5 命令队列

- 所有 Modbus 请求（读、写）进入同一串行队列：同一时刻只等一帧应答。  
- 应答超时约 **800ms**，超时后继续处理队列后续命令。  
- 写成功后会乐观更新对应路的设备状态缓存，减少重复写。

## 6. 频率一览

| 项目 | 间隔 / 条件 | 说明 |
|------|-------------|------|
| 读轮询 | **约 100ms** | 仅在队列空闲时触发；忙于写时不会插读 |
| 指令间隔 | **约 5ms** | 上一帧应答（或超时）结束后，再隔 5ms 发下一帧 |
| 写触发 | 事件驱动 | 连接同步、读到差异、本地改写；不是固定周期写 |
| 应答超时 | **约 800ms** | 单帧无应答则放弃等待并继续队列 |

示意（多路需写时）：

```
连接 → 写C0 → (应答) → 等5ms → 写C1 → (应答) → 等5ms → …
       …写完且队列空 → 约每100ms 读整段 → 有差异则再逐点写
```

## 7. 注意事项

- 不使用 `0x0F` 批量写，以提高对只支持单线圈写设备的兼容性。  
- 线圈很多且大量不一致时，逐点 `0x05` + 5ms 间隔会拉长整段对齐时间，属预期行为。  
- 修改数量会增删输入端口，超出范围的连线会丢失。  
- 「1 基」只影响界面/属性显示（显示值 − 1 = PDU），线上地址仍是 PDU。  
- 保存工程时会持久化 **期望线圈状态**（`coilStates`）；加载后恢复勾选框，连接成功后再按期望写回设备。

# ModBus Discrete Input

## 1. 节点说明

通过 **Modbus TCP 主机** 读取从站 **离散输入（Discrete Inputs）**。数量与起始地址可配置；只读，不写。

## 2. 端口说明

### 输出

| 端口 | 类型 | 说明 |
|------|------|------|
| DI0～DIN-1 [addr] | VariableData | 布尔值，设备回读的离散输入状态 |

无输入端口。

## 3. 界面说明

- **IP / 端口 / Server ID**：连接参数（默认 `127.0.0.1:502`）。
- **数量 / 起始地址**：1～64；地址基址可选 **0 基 (PDU)** 或 **1 基**。
- **离散输入勾选框**：只读显示；开=绿色，关=灰色。

外部控制：`/host`、`/port`、`/serverId`、`/inputCount`、`/addressBase`、`/inputStartAddress`。  
状态反馈：`/DI0`～`/DIN-1`。

## 4. 功能码与轮询

| 类型 | 读 | 写 |
|------|----|----|
| 离散输入 | FC `0x02` | 无 |

- 连接成功后约每 **100ms** 轮询读整段 DI（队列空闲时）。  
- 命令串行；应答超时约 **800ms**。  
- 状态变化时更新输出端口与 OSC 反馈。

## 5. 使用说明

1. 填写设备 IP、端口、从站 ID，以及 DI 数量与起始地址。  
2. 连接后从输出端口读取各路 DI。  
3. 保存工程时只持久化连接参数、数量、地址基址、起始 PDU 地址；**DI 状态不落盘**，连接后由 FC02 轮询从远端读回。

## 6. 注意事项

- 协议层始终使用 **PDU（0 基）**；选「1 基」只影响界面/属性显示（显示值 − 1 = PDU）。  
- 修改数量会增删输出端口，超出范围的连线会丢失。  
- DI 为只读镜像：本地缓存仅反映最近一次读回，重新打开工程后需等连接轮询才有有效状态。
