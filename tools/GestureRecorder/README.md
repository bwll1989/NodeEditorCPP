# Flow Gesture Recorder — 手势动作库录制工具

独立小工具，用于录制手势动作库（`.gesture` 文件），供 Flow 的 **Gesture** 节点加载做实时手势识别。

## 运行前提

把编译产物 `GestureRecorder.exe` 放在 **Flow 的 bin 目录**下运行（与 Flow.exe 同级），
它复用 `plugins/Models/` 里的两个 MediaPipe ONNX，不携带自己的模型。

## 使用流程

1. 点「打开摄像头」（或打开视频文件），画面内会叠画检测到的手部骨架。
2. 输入标签名（如 `fist`）点「添加标签」，确保列表里选中它。
3. 对着镜头比划手势，**按住「按住采样」**（约 5 帧/秒，每次采集自动入库 5 个增广模板：原样/旋转 ±12°/缩放 0.9/1.1 + 微噪声）。
4. 换角度 / 换距离再采几帧（每个标签建议采 3~5 次，即 15~25 个模板）。
5. 点「保存」，输出 `.gesture` 文件（首次保存会弹路径对话框；之后采样释放时自动保存）。
6. 把 `.gesture` 导入 Flow **媒体库**（自动进入 Gestures 分类），拖到画布即可创建 Gesture 节点。

**只需录一只手**：特征提取时左手会自动镜像成右手等效，录制与识别左右手通用。

**调阈值**：预览画面左上角会实时显示「最接近： 手势（相似度%）」——比划各个手势观察这个分数，
把每个手势的阈值设在「自己最高分」和「与别的手势混淆分」之间。

## 界面说明

- **打开库 / 保存**：`.gesture` 为 JSON 格式，可直接进 git / 拷贝到现场机器；首次保存弹路径对话框（即新建库）。
- **标签列表**：选中哪个标签，采样就存进哪个；每个手势可单独设阈值（选中后改「选中标签阈值」）。
- **撤销上一帧**：删掉选中标签最近采的那一批（5 个增广模板）。
- 采样过程中每采满一次会自动保存（已指定文件时），崩溃也不丢样本。

## 图标

程序窗口与 exe 文件图标为 `res/icons/finger.png`（经 `recorder.qrc` 与 `app.rc` 嵌入，随源码同步，无需外部文件）。

## 文件格式

```json
{
  "format": "flow-gesture",
  "version": 1,
  "type": "hand",
  "featureDim": 64,
  "gestures": [
    { "label": "fist", "threshold": 0.9, "samples": [[64 个浮点数]] }
  ]
}
```

特征 = MediaPipe handpose 21 点米制坐标展平（63 维）+ 左右手标志（1 维，v2 中已镜像归一、恒 0）。
本工具与 Gesture 节点共用 `GestureFeature.hpp` / `GestureLibrary.hpp` 的同一份副本，
两端格式与特征公式严格一致，**改动必须同步两份拷贝**。库文件含 `featureVersion: 2`，
旧 v1 库加载时节点会提示重录（v1 相似度被手性维度主导，精度不可信）。
